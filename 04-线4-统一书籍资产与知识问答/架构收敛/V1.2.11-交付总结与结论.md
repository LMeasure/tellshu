## 六、R2 架构与安全评估

| 维度 | 评估结论 |
|---|---|
| 存储分级 | ≥6 类：词典静态资源、用户私有导入书、用户音频/ASR 产物、AI 学习稿、发现检索索引快照、临时/中间产物 |
| 接入方式 | 词典：**只切 `VITE_DATA_BASE_URL` 指向 R2 public bucket，不迁 410MB 数据、不改前端代码**；私有存储走 `shushu-private` + 预签名 URL |
| 适配器 | 定义 `ObjectStorage` 接口（upload/download/delete/getSignedUrl/head），后端 `server/` 实现，前端不直连 R2 SDK |
| 安全边界 | 七条强制规则：公私有桶分离、私有无公网裸链、预签名逾期失效、密钥仅服务端 `.env`、路径前缀隔离、最小权限策略、版本化/生命周期 |
| 成本模型 | **不编造数字**：列出待核实单价（R2 存储/请求费、LLM token、ASR 时长），即使免出口费仍须算请求费 |
| 风险 | RK-6（误迁移 410MB）、RK-7（公网裸链泄露）、RK-9（编造成本）已在阶段 1B 风险清单与门禁 G10/G12 覆盖 |
| 当前状态 | P1 设计完成；R2 账户未注册/未配置/未上传（红线禁止本轮） |

## 九、最终结论

1. **阶段 1B 是否就绪？** —— 架构设计（P1）层面就绪；决策/预演/实施/验收（P2–P5）均未开始，**整体不就绪**。
2. **需要负责人签批什么？** —— G11：D1–D7 与 Q15–Q28 的书面批准/否决（尤其 D2 废止 `__public__`、D3 ENABLE 终审、D4 供应商、D6 R2 授权、D7 计费）；以及 OP-5 R2 预算授权、OP-7 备份 SLA。
3. **R2 开通后可推进什么？** —— G10（词典切 base URL + 私有桶）、G12（R2 真实单价回填）。词典采取低风险「只切 URL 不迁数据」路径，开通即可实施。
4. **不依赖 R2 可先行什么？** —— G1–G7、G9（四角色、RLS、复合外键、配额幂等、Dexie 升级、临时库预演）均属 R2 无关项，可在 G8 备份基础具备、负责人授权后启动；但任一实际 DDL/代码改动仍须明确授权，本文不自行进入实施。
5. **绝对红线（本轮已遵守，后续仍须遵守）** —— 不编造数据/成本、不升级版本、令牌仅后端 `.env`、不触碰并行未提交改动、不代注册 R2、文档完成 ≠ 实施完成。
