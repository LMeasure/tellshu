### 2.1 V1 整词判定与 V2 逐字母判定的差距（明确列出）

| 维度 | V1（开工） | V2（目标） |
|---|---|---|
| 判定粒度 | `judgeSpelling(input, answer)` 整词 trim+lower 全等 | 逐字符 `char.toLowerCase() === word.word[index].toLowerCase()` |
| 错误事件 | 一次错误整词提交 = **1 条** | 每个真实错误字母 = **1 条** |
| 输入进度 | 无（一次输入整词） | `typed_prefix` 持久化，错误后清零 |
| 连续正确 | 整词提交正确 +1 | 拼完整个单词 +1；错误字母归零 |
| 完整答题统计 | 错误提交计入 `total_attempts`/`wrong_attempts` | 错误字母**不计入**，只有拼完整词才算一次完整提交 |
| SRS | 整词 COMPLETED 时交接（D2） | 同上；错误字母**不触发** |
| 提示音 | 无 | 每个错误字母立即播放 |
| 错词本 | 只有会话级双指标 | 按 `(owner, word_id)` 合并记录 + 错误次数 + 最近错误时间 |
| 页面交互 | 输入整词 + 回车/提交按钮 | 受控单字符输入 + 串行队列，无提交按钮 |
| schema | v14 事件表 | **同一张 v14 表**，行内可选字段扩展，零 version/stores/迁移 |
