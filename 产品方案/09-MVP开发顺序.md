# MVP 开发顺序（Development Roadmap）v0.1 —「述树」零基础英语

> 前置：技术选型 v0.1 已确认。本步把前 8 步方案拆成可验证的里程碑（Phase 0–3），每阶段给出**范围、技术落点、可验证产出、退出标准**，并附功能覆盖矩阵。
>
> 范围界定：**MVP = Phase 0 + 1 + 2（Web App）**；Phase 3 为后续出 App/小程序，不计入 MVP 验收。
> 北极星指标：**7 日留存率**（见 01-PRD §3），每阶段都对准「每天愿意回来」。

## 1. Phase 0 — 骨架与核心闭环（纯 mock）

**目标**：用本地 JSON mock 把产品「跑起来」，验证交互与视觉，不接任何后端/语音/AI 真实能力。

**范围（含页面）**
- 前置门：启动/登录（mock 游客）、诊断测试（5 题梯度，mock 题）。
- 首页 Tab：首页/今日学习（mock 每日任务）、搜索/AI（仅搜索模式）、学习路径总览、学习流程（知识卡 + 单词/句型卡 mock）、练习结果。
- 发现 Tab：发现（筛选 chips + 双列卡片网格 mock）、课程详情。
- 我的 Tab：个人中心（mock 进度）、设置（本地开关生效）、收藏列表、集合详情。
- 全局：底部 Tab、TopSearchBar、复用组件库（Card/Button/Tabs/Progress/空/加载/错误态）、深色模式、375px 适配。

**技术落点**
- Vite + React + TS + Tailwind + shadcn/ui（技术 §2）；React Router v6；Zustand（内存态）。
- 绿色多巴胺设计令牌（组件树 §0）。
- TTS/ASR/AI **规则兜底**：发音用 mock 音频占位、跟读给假评分、AI 解释用静态模板。

**可验证产出（Done）**
- [ ] 4 个 Tab 与前置门可切换，375px 真机/模拟器视觉通过。
- [ ] 诊断 5 题跑通 → 生成 mock 每日任务 → 进学习流程。
- [ ] 知识卡/单词卡按 Linguabase 字段渲染（含 `word_hint`、点读按钮、慢速、收藏星标），字段缺失走降级（04 附录 A）。
- [ ] 练习即时对错反馈、练习结果成就弹窗（完成度≥80% 每日 1 次，06 §8.1）。
- [ ] 空/加载/错误三态在列表/详情/流程页可见。
- [ ] 深色模式一键切换，主色 ≤2 + 强调色符合规范。

**退出标准**：产品 demo 可在手机浏览器完整走完一次核心闭环，视觉与交互获确认。

## 2. Phase 1 — 本地持久化与留存引擎（离线可用）

**目标**：学习数据本地化，把「记忆→运用→掌握」分层 SRS 与可视化进度做成真实能力，**完全离线可用**。

**范围（新增/升级）**
- 数据层：Dexie 落 `vocab/daily_plan/diagnose_result/favorite/collection/reading_time_aggregate/achievement`；Zustand persist 落 `settings`/UI/session（技术 §3.2）。
- 学习闭环强化：跟读 ASR（Web Speech API 粗评分，技术 §5）、练习题型（选词义/听写/拼写，干扰项同 difficulty_level 抽取，05 §5.7）。
- 分层掌握（核心留存引擎）：生词本 → 闯关层（连续对 5 次、同一题型不做轮替、10min/1h 排程）→ 运用层（造 2 句，AI 离线缓存降级）→ 掌握层（A-Z + 同根聚合）；错题本合并闯关层、错词回流（06 §4）。
- 复习 Tab：复习队列（生词+错题合并）、错题本、闯关页。
- 我的：导入（书籍/音频/文章，本地解析 mock）、阅读/听书（长按选词加生词本）、个人中心微信读书式可视化（每日掌握单词量 + 阅读时长 + 周/月/年/总，06 §7.3）、成就墙。
- 离线：学习相关页 ✅完全离线，OfflineGate 拦截联网页（04 附录 B）。

**技术落点**
- IndexedDB(Dexie) + Zustand persist + dirty 同步（技术 §3.2）；Web Speech API（TTS/ASR 兜底，技术 §4-§5）。

**可验证产出（Done）**
- [ ] 关闭网络仍可学：卡片/知识卡/复习/错题本/闯关全部离线可用。
- [ ] 加入生词本→10min/1h 排程出现→连续对 5 次升运用层→造 2 句（离线缓存校验）→掌握层 A-Z+同根展示。
- [ ] 错题自动入错题本并合并闯关层；错词反复出错回流。
- [x] 导入文章/书籍（及 .txt 书籍、录音转写）→阅读长按/点按选词→生词本新增→按 SRS 次日复习出现。
- [ ] 个人中心进度表（周/月/年/总）随学习数据实时更新；阅读时长含听书。
- [ ] 成就去重（里程碑>完成度合并 1 卡，每日 1 次）生效。
- [ ] 进度本地暂存，联网自动同步不丢失。

**退出标准**：单人离线可完成「学→练→复习→掌握」完整飞轮，7 日留存预埋点全部在线。

## 3. Phase 2 — 云端社交与 AI/语音能力

**目标**：接入真实后端与智能能力，把社交、AI、专业发音评测做真，形成网络效应与「敢开口」。

**范围（新增）**
- 后端：Supabase（Postgres+Auth+Realtime+Storage），RLS 策略落地（技术 §3.3）。
- 社交 UGC：笔记流（点赞/评论/回复 + 中英翻译）、用户主页（关注）、私信（≤2 未回复上限，06 §6.5）、消息列表。
- AI：搜索 AI 模式、运用层造 2 句语法+句义校验（LLM）、笔记评论翻译、对话陪练（技术 §6）。
- 语音升级：ASR 接 Azure Pronunciation Assessment 音素级评分+纠错（技术 §5）；TTS 接云端预生成缓存。
- 内容：Linguabase 包走 CDN/对象存储，首次全量、version 增量、音频懒加载（技术 §3.4）。
- 同步：本地 dirty → 云端增量上传（冲突本地最新为准）。

**技术落点**
- Supabase（技术 §3.3）；LLM 国内模型为主（技术 §6）；Azure ASR（技术 §5）；CDN 增量（技术 §3.4）。

**可验证产出（Done）**
- [ ] 注册/登录可用；学习数据跨设备同步。
- [ ] 发布笔记→他人可见可点赞评论；评论中英翻译切换正确。
- [ ] 关注作者；发起私信，对方未回复前最多 2 条，回复后解限。
- [ ] 运用层造 2 句由 LLM 校验语法+句义，正确升掌握层。
- [ ] 跟读给出音素级准确度与纠错（非粗评分）。
- [ ] Linguabase 包首次下载 5–20MB、音频懒加载；version 更新生效。

**退出标准**：产品具备社交网络效应与真实 AI/发音反馈，达到对外推广质量。

## 4. Phase 3 — 出 App / 小程序（后续，非 MVP）

**目标**：把验证过的 Web App 打包为原生/小程序，扩大分发。

**范围**
- PWA（Vite PWA 插件）：离线缓存 + 桌面图标。
- Capacitor：包裹同一 Web 代码出 iOS/Android，原生麦克风/通知权限（技术 §8）。
- 可选 Taro（React 语法）出微信小程序。

**退出标准**：应用商店可安装包或小程序上线，核心功能与 Web 一致。

## 6. 里程碑节奏建议（参考）

- **Phase 0**：2–3 周（骨架+核心闭环 demo，快速拿视觉确认）。
- **Phase 1**：4–6 周（留存引擎是成败关键，最该打磨）。
- **Phase 2**：4–6 周（社交+AI+语音，对外推广前完成）。
- **Phase 3**：2–3 周（打包，可并行于 Phase 2 末期）。

**检查点**：每 Phase 结束做一次可用性测试（零基础用户 5 人），以「今日任务完成率≥60%、跟读完成率≥50%」为 Phase 1 准出参考（01-PRD §3）。

## 7. 风险与对策（贯穿开发）

| 风险 | 对策 |
|---|---|
| Phase 1 留存引擎逻辑复杂易错 | 先用 mock 验证状态机（06 §4），再接 Dexie |
| 浏览器 ASR 仅 Chrome | Phase 1 粗评分，Phase 2 接 Azure，不阻塞 MVP |
| LLM 成本/合规 | MVP 规则兜底，Phase 2 国内模型为主 |
| 社交冷启动 | 笔记流先允许发自身笔记+系统示例，再引 UGC |
| 离线同步冲突 | 单人数据本地最新为准，dirty 增量 |
