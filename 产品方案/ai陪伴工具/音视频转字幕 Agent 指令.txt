# 六、核心数据结构


Transcript：


```ts
{
 id:string,

 language:string,

 duration:number,

 segments:[
  {
   start:number,

   end:number,

   text:string
  }
 ]
}

要求：

每条文本必须包含：

开始时间
结束时间
内容
