# 组件树（Component Tree）v0.1 —「述树」零基础英语

> 前置：数据模型 v0.1 已确认。本步把全局布局 → 底部 Tab → 页面 → 组件逐层展开，标注**复用组件**与**状态来源**（数据实体见 06）。技术栈：React + Tailwind + shadcn/ui，移动端 375px 优先，深色模式。
>
> 约定：
> - `【复用】` = 跨页复用的基础/业务组件（库见 §1）。
> - `↺ 状态来源` = 该组件读写的实体（见 06 数据模型），标注 `[Linguabase]`/`[本地]`/`[联网]`。
> - 缩进 = 组件嵌套层级。

---

## 0. 设计令牌（贯穿全树，绿色多巴胺系）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--brand` | 鲜亮薄荷绿/草绿（高饱和） | 主色：主按钮、激活 Tab、进度条 |
| `--brand-deep` | 沉稳深绿 | 辅助：分隔、次级强调、A-Z 分组头 |
| `--accent` | 亮黄/珊瑚橙 | 强调色：对勾、奖励、CTA、成就弹窗 |
| `--bg` / `--bg-soft` | 浅底/卡片底 | 背景与卡片 |
| `--radius` | 16–20px | 圆角卡片（Mobbin 风） |
| `--shadow` | 柔和投影 | 卡片浮起 |
| 断点 | 375px（max-width 容器，居中适配更大屏） | 移动端优先 |
| 深色模式 | `light`/`dark`/`system`（设置驱动） | 全组件 `dark:` 变体 |

> 所有组件默认接受 `className` 透传，颜色走 CSS 变量，确保深浅色一键切换。

## 1. 复用组件库（12 类，见 05 §6）

| 组件 | 类型 | 主要变体 | 复用页 |
|---|---|---|---|
| `Card` | 基础 | `course` / `word` / `note` / `vocab` | 发现/学习/复习/我的 |
| `Button` | 基础 | `primary`(品牌) / `accent`(CTA) / `ghost` / `icon` | 全部 |
| `Tabs` | 基础 | 顶部分段（发现/笔记流、练习/结果） | 发现/学习流程 |
| `Progress` | 基础 | `bar`(学习进度) / `ring`(连续天数) / `streak`(x/5) | 首页/学习/复习 |
| `Sheet` | 基础 | 底部抽屉（筛选/集合选择/发布） | 发现/收藏/发布 |
| `Skeleton` | 状态 | 卡片/列表/详情骨架 | 全部加载态 |
| `EmptyState` | 状态 | 默认/搜索无果/无收藏 | 全部空态 |
| `ErrorState` | 状态 | 重试/离线提示 | 全部错误态 |
| `Toast` | 反馈 | 即时音效+微动效（单卡完成不弹窗） | 全部 |
| `ReadAloud` | 业务 | 常速/慢速、逐词点读、迷你播放器 | 卡片/阅读/跟读 |
| `FollowEval` | 业务 | 录音+ASR 评分+纠错浮层 | 跟读/练习/运用 |
| `OfflineGate` | 业务 | 友好提示页「信号迷路了，连上网继续学！」 | 登录/诊断/搜索AI/笔记/导入/私信 |

## 2. 全局布局（AppShell）

```
AppShell                                     ↺ 全局容器（375px 居中，主题提供者）
├─ TopSearchBar        【复用】              ↺ [Linguabase]词库 + [联网]AI（模式切换，见 05 §2.2）
├─ BottomTabBar        【复用】              ↺ 4 Tab：首页/发现/复习/我的（常驻）
├─ ReadAloudMiniPlayer 【复用·业务】         ↺ [Linguabase]音频（全局可呼出，慢速/常速）
├─ FollowEvalOverlay   【复用·业务】         ↺ [本地]vocab（跟读评分，不离开当前页）
├─ Toast               【复用】              ↺ 即时反馈
├─ AchievementPopup    【复用】              ↺ [本地]achievement（去重合并，每日1次，见 06 §8.1）
└─ OfflineGate         【复用·业务】         ↺ 离线进入❌页时拦截
```

## 8. 复用组件 → 状态来源映射

| 复用组件 | 主要状态来源（06 实体） | 离线行为 |
|---|---|---|
| `ReadAloud` | content_letter/word/pattern.audio_path | ✅ 预缓存音频离线可用 |
| `FollowEval` | vocab（跟读评分） | ✅ 本地 ASR（若离线 TTS/ASR 引擎） |
| `ChallengeCard` | vocab(practice) + content_word(干扰项) | ✅ 完全离线 |
| `ProgressChart` | reading_time_aggregate | ⚠️ 仅本地记录，联网同步 |
| `NoteCard/Like/Comment` | note/note_like/comment | ❌ OfflineGate |
| `FollowButton/DM` | follow/dm | ❌ OfflineGate |
| `AchievementPopup` | achievement | ⚠️ 本地已解锁可看，新成就联网补弹 |
| `OfflineGate` | — | ❌ 拦截❌页 |
