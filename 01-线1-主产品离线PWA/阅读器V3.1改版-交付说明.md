## 一、做了什么

### 1. 底部导航栏常驻 + 面板滑出（需求一）
- `ReaderControlCenter` 重构：原面板顶部的 5 项导航（目录/笔记/进度/听书/设置）改为**常驻屏幕最底部**（`h-14` 独立栏，`bg-card` + 顶边线），默认只显示栏、不展开面板。
- 点击某导航 → 从底部**向上滑出固定面板层**（覆盖内容区、`bottom-14` 停在导航栏之上、`rounded-t-2xl`、`animate-slide-up`）；再点当前项 / 点空白遮罩 → 收起。
- 面板内部 `stopPropagation`（拖滑块 / 输页码 / 切导航不误关）。
- 「单击正文 Toggle 面板」逻辑保留（`PageFlipContainer.handleClick` → `Reader.togglePanel`）。

### 2. 取消「阅读/记忆」总开关 → 抽屉式滑出（需求二）
- 设置页**移除顶部 Segmented（阅读/记忆）**，`SettingsPanel` 仅保留「阅读」设置。
- 阅读设置底部新增「**记忆设置 ›**」行，点击从**右侧滑出抽屉**（`animate-drawer-in`，不透明全遮罩）。
- 抽屉内含「**记忆模式**」开关联动 `mode`（`onModeChange`），以及记忆配置（隐藏方式/比例/中英文目标/含标点/自主选择说明）。
- 抽屉 **X = 返回主面板**，**点空白 = 关闭整个控制中心**。
- props 由 `tab/onTabChange` 改为 `mode/onModeChange/onCloseAll`。

### 3. 首行缩进按钮去文字（需求三）
- 去掉「开/关」字样，仅靠颜色区分：未开 = 绿框白底绿字 / 已开 = 绿框绿底白字（文案统一为「首行缩进」）。

### 4. 字体/背景/翻页二级弹窗全遮罩（需求四）
- 三个选择器（原嵌套 `Sheet`）改为 **`CoverOverlay` 不透明全遮罩**，完整覆盖主面板。
- **X = 回主面板**；**点空白处 = 全部关闭**（关闭整个控制中心）。关/开语义与 V3.0 一致。

### 5. 一页一屏加固（需求五）
- 非滚动模式的页面层本就 `overflow:hidden`（`.pf-fit` / `.pf-track-page`）。本轮补两道保险：
  - **字体就绪后重测分页**：`document.fonts.ready` 后重跑 `packByHeight`，避免系统字体未就绪导致测量偏低、整页溢出被裁。
  - **安全余量 `PAGE_SAFETY` 6 → 12px**：杜绝末行因亚像素/字体度量误差被裁。
- 分页仍按「真实渲染高度」贪心装填、超长段落按词边界拆片段跨页，放不下的整行自然落到下一页，**不截断、不丢行、不多行**。

### 6. Bug 6 修复：进度条拖不动
- **根因**：`ProgressPanel` 圆点用 `setPointerCapture`，但缺少 `touch-action: none`。触摸设备上浏览器把横向拖动识别为滚动手势 → 触发 `pointercancel` → `draggingRef` 清空 → 拖动立即失效。
- **修复**：改用 **window 级 `pointermove`/`pointerup`/`pointercancel` 监听** + 圆点 `style={{ touchAction: 'none' }}`，定位计算（40px/页）保留。桌面/移动端均稳定。

### 7. Bug 7 修复：长按划词失效
- **根因**：slide 模式原生 `touchmove` 里 `e.preventDefault()` 在长按选词过程中（手指微动 >8px）掐断原生选区，导致划词菜单弹不出。
- **修复**：
  - `onStart`/`onMove`：检测到**活跃选区（`!getSelection().isCollapsed`）时，不抢占翻页手势、绝不 `preventDefault`**，交还浏览器处理文本选择。
  - `handleClick` / `Reader.togglePanel`：存在活跃选区时**跳过单击逻辑**，不清除选区、不切换面板。
  - `selectionchange` 监听（仅 read 模式）正常捕获 `getClientRects()` 弹划词菜单。
