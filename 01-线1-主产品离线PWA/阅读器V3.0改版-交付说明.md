## 三、关键实现说明（供后续维护）

### 1. 「一页即一屏」怎么做到不溢出
- **测量探针**：`Reader` 内一个隐藏 div（`.measure-probe`），宽度 = 内容区宽 − 左右边距，
  字号/行距/字体与正文 `<article>` 完全一致，`white-space:pre-wrap; overflow-wrap:break-word`。
- **必须测「真实渲染文本」**：正文按分句渲染、句间以一个空格拼接，故探针文本 = `splitSentences(片段).join(' ') + ' '`
  （不是原始切片，否则中文长段会因少算空格而**少算行数 → 溢出**）。同时去掉了句级 `px-0.5`（内边距会改变换行）。
- **切页算法**（`packByHeight`，纯逻辑可单测）：贪心 + 二分找「剩余高度内最大的字符数」，
  超长段落切成片段跨页；英文回退到词边界；每页高度预算 = `内容区高 − 上下内边距(48) − 安全余量(6)`。
- **坐标不漂**：片段仍带 `data-para` + `data-para-start`，`selectionCapture` 把偏移**还原到整段坐标系**，
  划线/想法跨页依然对得上。

### 2. 交互与手势隔离
- 单击 = 清选区 + Toggle 面板；长按 = 原生划词。触摸 `touchstart→click` 之间加
  **时间阈值 400ms / 位移阈值 10px**，滑动翻页不会误触面板。
- **平滑翻页的翻页手势**：横向拖动（跟手）；`book/cover` 用横向滑动（>60px）；
  另有键盘 ←/→。**取消了「点左/右 1/4 翻页」**（与「单击=Toggle 面板」冲突，按需求一·3 处理）。

### 3. 阅读位置锚定
重新分页（改字号/行距/边距/字体，或窗口尺寸变化）后，用「上一次提交记录的首段」再定位到新页，
避免跳页。实现见 `Reader` 内 `anchorRef` 两个 effect（顺序敏感，注释已标明）。

6. **分页边界**：极端字体/超长不可断行内容下，页面层为 `overflow:hidden`（按需求「严禁上下滑动」），
