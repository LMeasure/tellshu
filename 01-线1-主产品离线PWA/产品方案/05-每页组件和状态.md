# 每页组件和状态（Components & States）v0.2 —「述树」零基础英语

> 前置：页面清单 v0.2 已确认（含附录 A 字段映射、附录 B 离线矩阵）。本步逐页拆解**组件、四态（加载/空/错误/正常）、交互与数据流**，作为第 6 步数据模型、第 7 步组件树、第 9 步开发顺序的直接输入。
> 约定：数据源标记 `[本地mock]` `[Linguabase]` `[联网]`；状态标记 `L`加载 `E`空 `R`错误 `N`正常；底部 Tab 常驻不重复列。

---

## 0. 通用规范（所有页面复用）

### 0.1 全局常驻组件
| 组件 | 说明 | 状态 |
|---|---|---|
| `BottomTabBar` | 首页/发现/复习/我的 4 Tab，当前项高亮（绿色强调） | N：高亮项；离线 Tab 不禁用 |
| `TopStatusBar` | 时间/信号/页面标题（部分页隐藏标题用大标题） | N |
| `ReadAloudMiniPlayer` | 全局点读迷你播放器：慢速/常速、逐词点读、关闭 | N：隐藏/展开；`R`：音频缺失静默隐藏（见附录 A） |
| `FollowEvalOverlay` | 全局跟读评测浮层：录音→ASR→评分+纠错（参考百度翻译） | `L`识别中；`N`结果；`R`识别失败重试 |
| `GestureLayer` | 长按=收藏 / 右滑=已掌握 / 左滑=错题（卡片级） | N |
| `OfflineGate` | 离线进入❌页时显示「信号迷路了，连上网继续学！」+返回首页（见附录 B） | N |

### 0.2 四态规范
| 态 | 呈现 | 触发场景 |
|---|---|---|
| `L` 加载 | 骨架屏（卡片/列表/头像占位），不出现原生 loading 圈 | 首屏、下拉刷新、切换 Tab、拉取 Linguabase/网络数据 |
| `E` 空 | 引导式插画 + 一键行动（如「去发现」「导入文章」「开始诊断」） | 无数据（首次/筛选项无结果/无收藏） |
| `R` 错误 | 错误态插画 + 重试按钮 + 文案（非技术报错） | 网络失败、解析失败、数据异常 |
| `N` 正常 | 业务内容 | 数据就绪 |

### 0.3 设计令牌与断点
- 移动端 375px 优先；最大宽度容器 430px 居中（平板/桌面）。
- 绿色多巴胺：主色薄荷绿/草绿、辅助深绿/暖白、强调亮黄/珊瑚橙（对/奖励/CTA）。
- 深浅色模式：所有组件 `dark:` 变体齐备；设置可切。

### 0.4 数据流约定
- `[本地mock]`：首版写死的本地 JSON（用户/进度/收藏/笔记草稿），为后续 Supabase/Firebase 预留仓储接口。
- `[Linguabase]`：首版唯一学习内容来源，首次联网全量下载本地，后续增量更新（附录 B）。**诊断题目亦存储于本地 Linguabase 包**，重诊断可离线进行；仅**首次诊断须联网校验**以防游客篡改本地数据获取过高等级（见 §1.2、附录 B）。
- `[联网]`：笔记流/私信/搜索AI/导入解析，离线不可用时走 `OfflineGate`。
- 写操作统一经 `useStore`（zustand/context）落本地，联网后按附录 B 同步。

## 1. 前置门

### 1.1 启动 / 登录
- **组件**：`BrandHero`(述树+多巴胺绿+slogan)、`LoginMethods`(微信/手机一键)、`GuestEntry`(游客模式)、`PrivacyHint`、`OfflineGate`(联网校验)。
- **四态**：`L`登录中；`N`就绪；`R`登录失败（重试/游客兜底）。无「空」态。
- **关键交互**：一键登录→诊断引导；游客→本地 mock；退出登录返回此页。
- **数据流**：入 `user`(本地mock)；出 `authToken`/`guestFlag` 落本地；**联网**校验账号（离线禁用，见附录 B）。

### 1.2 诊断测试（每 7 天）
- **组件**：`DiagnosticProgress`(第 x/5 题)、`QuizCard`(选择题)、`EncourageToast`(答错鼓励文案，无错音)、`DiagnosticReport`(等级+起始 topic_id+建议路径)、`StartTodayBtn`。
- **数据来源**：`[Linguabase]` 按 `difficulty_level` 抽 5 题（1-2=L1 字母 / 3-4=L2 高频词 / 5=L3 句型），见页面清单 §1.2。**首次诊断须联网校验**以防游客篡改本地数据获取过高等级；**每 7 天重诊断可离线**，使用本地 Linguabase 包中的题目。
- **四态**：`L`拉题；`N`答题；`E`无（必出题）；`R`拉题失败→重试/稍后。
- **关键交互**：无倒计时、答错不批评、鼓励文案自动下一题；**兜底**：前 2 题错≥1 即终止推入门计划；全对推 L3；结果写 `plan.topic_id`。
- **数据流**：入 Linguabase 诊断题；出 `diagnoseResult`/`dailyPlan`(落本地)，触发首页今日任务卡。

## 2. 首页（Tab 1）

### 2.1 首页 / 今日学习
- **组件**：`SearchBar`(搜索/AI 切换 segmented)、`TodayTaskCard`(连续天数/进度/奖励横条/每日掌握单词量/开始按钮)、`PathOverviewEntry`、`StreakBar`、`RewardStrip`、`OfflineGate`(部分离线)。
- **数据来源**：`[本地mock]` 进度/连续天数；`[Linguabase]` 今日任务内容。部分离线可看本地完成数（附录 B）。
- **四态**：`L`今日任务加载；`N`正常；`E`未诊断→引导诊断；`R`任务加载失败重试。
- **关键交互**：点今日任务→学习流程；点路径节点→回看知识卡/进节点；搜索切 AI。
- **数据流**：读 `user.streak`/`dailyPlan`/`progress`；点开始→写 `session.start`。

### 2.2 搜索 / AI 问答
- **组件**：`ModeSwitch`(搜索/AI)、`SearchInput`、`ResultList`(词卡/课程/笔记)、`AIChatBubble`、`AskAIEntry`(上下文唤起)。
- **数据来源**：搜索模式 = `[Linguabase]` 本地全量词库查询，**完全离线可用**；AI 模式 = `[联网]` 对话（离线禁用，走 `OfflineGate`）；课程结果来自 `[Linguabase]`。
- **四态**：`L`搜索中/AI 思考；`N`结果/`E`无结果（换词/引导）；`R`网络失败重试。
- **关键交互**：切模式；结果项进详情；AI 发问→解释/纠错/例句。
- **数据流**：读 Linguabase 词库；AI 对话走联网，本地缓存最近会话（部分离线只读缓存）。

### 2.3 学习路径总览
- **组件**：`StageAxis`(字母→音标→词汇→句型→对话)、`StageNode`(完成度/当前标记)、`NodeReviewCard`(回看知识卡)。
- **数据来源**：`[Linguabase]` 节点数据；`[本地mock]` 完成度。
- **四态**：`L`加载；`N`；`E`无（不应出现）；`R`失败重试。
- **关键交互**：点节点→回看知识卡/进该节点学习流程。
- **数据流**：读 `progress.path`；写节点进入事件。

### 2.4 学习流程（共享容器）
- **组件**：`StepProgress`(顶部进度条)、`KnowledgeCard`(Linguabase 渲染区，**无视频**，见附录 A)、`WordCard`(英文/中文/音标/图片/例句/`word_hint`/点读/慢速/收藏)、`FollowEval`(录音+评分)、`ExerciseArea`(选/配对/填空/排序/听写/跟读)、`NavPrevNext`(上一张/下一张)、`InstantFeedback`(即时对错)、`ReadAloudMiniPlayer`(复用)。
- **数据来源**：`[Linguabase]` 知识卡/卡片/练习；`[本地mock]` 收藏/进度。
- **四态**：`L`卡片流加载（骨架）；`N`；`E`无（该节点无内容）；`R`数据异常→单卡静默跳过记日志（附录 A），全部异常→错误态重试。
- **关键交互**：上下张、点读、跟读评分、收藏、即时反馈；卡片手势（长按收藏/右滑掌握/左滑错题）。
- **数据流**：读 Linguabase 节点包；写 `progress`/`favorites`/`mistakes`/`consecutive_correct`；通关→练习结果。

### 2.5 练习结果（共享）
- **组件**：`ScoreBoard`(对错统计)、`StarBadgeAnim`(星星/徽章动画)、`MistakeList`、`FinishBtn`/`GoReviewBtn`、`AchievementToast`(成就触发规则见页面清单 §2.5)。
- **数据来源**：`[本地mock]` 进度；成就本地缓存（部分离线，新成就联网补弹，附录 B）。
- **四态**：`L`结算；`N`；`E`无；`R`保存失败（本地暂存，联网同步）。
- **关键交互**：完成→回首页/下一；去复习→复习模式；**成就**：完成度≥80% 每日 1 次祝贺弹窗、单卡仅音效微动效、3/7/14/30 里程碑合并徽章弹窗。
- **成就触发规则**（详见页面清单 §2.5）：单卡/单练仅即时音效+微动效不弹窗；完成度≥80% 每日 1 次祝贺弹窗；3/7/14/30 里程碑专属徽章弹窗；**同日合并与优先级**——若同天既达完成度又达里程碑，按「里程碑徽章 > 每日完成度」合并为 1 张卡片（上徽章+下祝贺文案），仅弹 1 次、不叠加；点「收下」或 3 秒无操作自动消失。
- **数据流**：写 `progress`/`streak`/`achievements`/`mistakes`(错题自动入错题本)。

## 5. 我的（Tab 4）

### 5.1 个人中心

- **关键交互**：看报表；进各子页。
- **数据流**：读 `progress`/`readingTime`/`stats`。

### 5.2 消息（私信列表）
- **组件**：`ConversationList`(头像/最后消息/未回复上限提示)、`UnreadDot`。
- **数据来源**：`[联网]` 私信（离线禁用）。
- **四态**：`L`列表骨架；`N`；`E`无会话（引导去笔记关注的人）；`R`失败重试。
- **关键交互**：进会话；从用户主页发起新私信。
- **数据流**：读联网 dm；写未读状态。

### 5.3 私信会话
- **组件**：`ChatBubbles`、`InputBar`、`SendBtn`、`UnrepliedHint`(对方未回复前最多 2 条)、`TranslateOpt`。
- **数据来源**：`[联网]` 实时通信（离线禁用）。
- **四态**：`L`历史骨架；`N`；`E`无消息（发第一条）；`R`发送失败（存草稿重试）。
- **关键交互**：发消息（≤2 限制）；对方回复后解限。

### 5.4 导入（书籍 / 音频 / 文章）
- **组件**：`ImportSource`(本地文件/粘贴/链接)、`TypePicker`(书籍/音频/文章)、`ParsingState`、`EnterReadBtn`。

- **四态**：`L`解析中；`N`；`E`无（引导选择）；`R`解析失败（重选/重试）。

- **数据流**：写 `importJob`(联网)；产出 `readingDoc` 落本地。

### 5.5 阅读 / 听书
- **组件**：`Reader`(正文；音频：字幕随语音高亮)、`ReadAloudFollow`(全局复用)、`WordSelectAdd`(长按选词→生词本)、`TimeTracker`(进度/时长)。
- **数据来源**：`[本地mock]` 文档；`[Linguabase]` 音频**仅覆盖字母/音标/单词/句型的发音**（离线可点读，附录 B）。**阅读/听书页的音频来自用户导入的文件本身，非 Linguabase**；若导入为纯文本（无音频），则点读/听书使用 **TTS**（联网生成或离线 TTS 引擎），不依赖 Linguabase 音频。
- **四态**：`L`文档/音频加载；`N`；`E`空文档；`R`加载失败重试。
- **关键交互**：长按选词加生词；听书时长计入个人中心。
- **数据流**：读 `readingDoc`；写 `vocab`(生词本)/`readingTime`。

### 5.6 学习分层（生词 / 运用 / 掌握）
- **组件**：`LayerTabs`(生词本/运用层/掌握层)、`AZGroup`(A-Z+同根聚合)、`CountBadge`、`EnterPractice`。
- **数据来源**：`[本地mock]` 分层数据（完全离线可读）。
- **四态**：`L`分层骨架；`N`；`E`某层空（引导去阅读/学习）；`R`失败重试。
- **关键交互**：进生词本闯关；进运用层造句。
- **数据流**：读 `vocab.layer`/`root`；写层间迁移。

### 5.7 生词本闯关
- **组件**：`ChallengeCard`(选词义/听写/拼写之一种，沿用上次题型不做轮替)、`StreakProgress`(连续对 x/5)、`SRSHint`(遗忘曲线排程提示)、`InstantFeedback`。
- **数据来源**：`[本地mock]` 生词+错题（**合并闯关层**，完全离线可用，附录 B）；`[Linguabase]` 音频（字母/音标/单词/句型发音）。**干扰选项**：从 Linguabase 同 `difficulty_level` 的其他词条中随机抽取 3 个 `definition_zh` 作为干扰项；若同难度词条不足 3 个，降级从相邻难度层抽取。
- **四态**：`L`出题骨架；`N`；`E`无待闯词（全部升层，撒花）；`R`失败重试。
- **关键交互**：作答；过关升层；错回流错题本。**规则**：加入即排 10 分钟/1 小时；须连续对 5 次（同一题型，不做轮替）；错词回流。
- **数据流**：读 `vocab`/`mistakes`；写 `consecutive_correct`/`layer`/`next_review`。

### 5.8 运用层（造句 + AI 校验）
- **组件**：`TargetWord`、`SentenceInput`、`AICheckFeedback`(语法/句义)、`MakeProgress`(造 x/2)、`SRSHint`(1/3/7/14/30 天复现提示)。
- **数据来源**：`[本地mock]` 运用词；`[联网]` AI 校验（离线禁用，缓存最近结果）。
- **四态**：`L`校验中；`N`；`E`无运用词；`R`校验失败（重试/稍后）。
- **关键交互**：造句→AI 校验→正确入掌握。
- **数据流**：读 `vocab(layer=运用)`；写 `layer`(→掌握)/`next_review`。

### 5.9 收藏列表
- **组件**：`CatTabs`(词/句/课)、`FavList`、`MoveToCollection`。
- **数据来源**：`[本地mock]` 收藏（完全离线可读）。
- **四态**：`L`列表骨架；`N`；`E`无收藏（引导去发现/学习）；`R`失败重试。
- **关键交互**：点进详情；加入/新建集合。
- **数据流**：读 `favorites`；写集合归属。

### 5.10 集合详情

- **数据来源**：`[本地mock]` 集合（完全离线可读）。
- **四态**：`L`骨架；`N`；`E`空集合（引导加内容）；`R`失败重试。
- **关键交互**：一键学习→学习流程；编辑。
- **数据流**：读 `collections`；写 `dailyPlan`(临时)/编辑。

### 5.11 设置

- **数据来源**：`[本地mock]` 偏好（**部分离线**可改本地，联网同步，附录 B）。

## 7. 全局状态机示例

### 7.1 跟读评测状态机（ReadAloud / FollowEval）
```
空闲 → 点读/录音 → 录音中 → ASR识别中(L) → 结果(N：评分+纠错) / 失败(R：重试)
```

### 7.2 卡片手势状态机（GestureLayer）
```
长按 → 收藏(toggle) ｜ 右滑 → 标记已掌握(升层) ｜ 左滑 → 加入错题本
```

### 7.3 离线降级状态机（参考附录 B）
```
进入页 → 检查离线等级
  ├─ ✅ → 正常(本地缓存)
  ├─ ⚠️ → 部分功能(本地只读/可改本地)
  └─ ❌ → OfflineGate(返回首页)
```
