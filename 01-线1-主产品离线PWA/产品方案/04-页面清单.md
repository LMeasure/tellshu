## 1. 前置门

### 1.1 启动 / 登录
- **目标**：建立账号（或游客），初始化本地数据，引导至诊断。
- **核心元素**：品牌「述树」（多巴胺绿）、slogan、一键登录（微信/手机）、游客模式、隐私提示。
- **进入方式**：App 冷启动 / 退出登录。**关键交互**：登录 → 诊断；游客 → 本地 mock 数据。

### 1.2 诊断测试（每 7 天一次）
- **目标**：测字母/发音/词汇量，定等级，生成学习计划与每日任务。
- **核心元素**：5 道分梯度选择题（从 Linguabase 按 difficulty_level 字段抽取：第 1-2 题 difficulty=1 字母辨识、第 3-4 题 difficulty=2 高频词认读、第 5 题 difficulty=3 句型理解）、进度条（显示当前第 x/5 题）、鼓励性文案（答错不批评）、完成报告（等级 + 对应 Linguabase 起始 topic_id + 建议路径）。兜底逻辑：前 2 题答错 ≥1 题即终止并推荐入门计划。
- **进入方式**：首次 / 每 7 天到点 / 个人中心「重新诊断」。**关键交互**：分步作答 → 报告 → 一键「开始今日学习」。

## 2. 首页（Tab 1）

### 2.1 首页 / 今日学习
- **目标**：当日唯一主入口，降低决策；展示连续天数/进度/奖励/每日单词量。
- **核心元素**：顶部搜索（搜索/AI 切换）、今日任务卡（开始按钮）、学习路径总览入口、连续天数条、进度/奖励横条、每日掌握单词量。
- **关键交互**：点今日任务 → 学习流程；点路径节点 → 回看知识卡/进入该节点；搜索切 AI。

### 2.2 搜索 / AI 问答
- **目标**：搜词/课程/笔记，或 AI 答疑陪练。
- **核心元素**：模式切换 segmented、搜索框、结果列表（词卡/课程/笔记）、AI 对话气泡。
- **进入方式**：首页顶部搜索。**关键交互**：切模式；结果项进详情；AI 发问 → 解释/纠错/例句。

### 2.3 学习路径总览
- **目标**：看全局进阶地图，回看节点知识卡。
- **核心元素**：阶段轴（字母→音标→词汇→句型→对话）、每节点完成度、当前所处标记。
- **进入方式**：首页内嵌入口。**关键交互**：点节点 → 回看知识卡 / 进入该节点学习流程。

### 2.4 学习流程（共享容器）
- **目标**：完成「知识卡→卡→跟读→练习→结果」一段学习。
- **核心元素**：顶部进度条、知识卡渲染区（Linguabase 数据驱动，无视频播放）、单词/句型卡（英文/中文/音标/图片/例句/`word_hint`/点读/慢速/收藏）、跟读录音+评分、练习区、底部上一张/下一张、即时对错反馈。
- **进入方式**：今日任务 / 课程详情 / 复习模式 / 集合一键学习。**关键交互**：上下张、点读、跟读、收藏、即时反馈。

### 2.5 练习结果（共享）
- **目标**：即时反馈本次练习，发奖励 / 导流错题。
- **核心元素**：对错统计、星星/徽章动画、错题列表、按钮（完成 / 去复习）。
- **成就触发规则**：
  - **全局弹窗触发条件**：当日学习计划完成度 ≥ 80% 时触发 1 次祝贺动效（撒花+音效+文案「太棒了！今日任务快完成啦！」），每日仅弹出 1 次，不重复触发。
  - **单次反馈（不弹窗）**：单个卡片完成、单次练习答对、单个闯关通关时，仅给予即时音效 + 微动效（如星星弹出、卡片发光），不触发弹窗。
  - **连续天数达成弹窗**：连续学习天数达到 3/7/14/30 天里程碑时触发专属徽章弹窗。
  - **同日合并与优先级**：若同一天既达 ≥80% 完成度又达连续天数里程碑，按「里程碑徽章 > 每日完成度」优先级，**合并为 1 张卡片**（上方徽章 + 下方祝贺文案），仅弹 1 次、不叠加弹窗。
  - **弹窗关闭**：用户点击「收下」后关闭；若无操作，3 秒后自动消失（音效播完即止）。
- **进入方式**：学习流程内练习完成。**关键交互**：完成 → 回首页/下一；去复习 → 复习模式。

## 3. 发现（Tab 2）

### 3.1 发现
- **目标**：探索课程/词单 + 笔记流，激发兴趣。
- **核心元素**：顶部搜索、筛选 chips（主题/难度/场景/时长/技能）、双列卡片网格（课程/词单）、「笔记」tab 切换、发布「+」。
- **关键交互**：筛选；点卡片 → 课程详情；切笔记 tab。

### 3.2 课程详情
- **目标**：了解课程并决定开始/收藏。
- **核心元素**：大图/预览、标签、简介、收藏按钮、开始学习、章节/节点列表。
- **进入方式**：发现页卡片点击。**关键交互**：收藏；开始 → 学习流程。

### 3.3 笔记流
- **目标**：浏览自己/他人笔记与感想（轻量社交）。
- **核心元素**：双列/单列信息流（封面图/标题/作者/点赞数）、发布「+」。
- **进入方式**：发现页「笔记」tab。**关键交互**：点赞；点卡片 → 笔记详情。

### 3.4 笔记详情
- **目标**：看笔记全文并互动。
- **核心元素**：图文内容、作者信息（关注）、点赞/收藏、评论列表（可中英翻译）、评论输入、回复。
- **进入方式**：笔记流卡片点击。**关键交互**：关注；评论（翻译）；回复；可选长按选词加生词。

### 3.5 发布笔记
- **目标**：发布自己的学习笔记/感想。
- **核心元素**：编辑器（图文/标签/关联词）、发布按钮、草稿。
- **进入方式**：笔记流「+」。**关键交互**：选图/写文/打标签/发布。

### 3.6 用户主页
- **目标**：看资料，关注/私信。
- **核心元素**：头像/昵称/简介、关注/粉丝数、关注按钮、私信按钮、TA 的笔记列表。
- **进入方式**：笔记详情/笔记流作者。**关键交互**：关注（toggle）；私信（对方未回复前最多 2 条）。

## 4. 复习（Tab 3）

### 4.1 复习
- **目标**：完成每日复习与间隔重复，清零错题。
- **核心元素**：每日复习任务卡、间隔重复队列、错题本入口、进度。
- **进入方式**：底部 Tab。**关键交互**：开始复习 → 复习模式；进错题本。

### 4.2 错题本
- **目标**：集中攻克错词。
- **核心元素**：错词列表（词/错因/次数）、一键复习、移出。
- **进入方式**：复习首页入口。**关键交互**：复习 → 闯关层；移出 → 掌握。

## 5. 我的（Tab 4）

### 5.1 个人中心
- **目标**：看学习数据与微信读书式可视化进度，聚合入口。
- **核心元素**：可视化（每日掌握单词量、阅读时长含听书 n 小时 m 分钟、周/月/年/总进度表）、连续天数、每日目标、提醒入口、导入入口、消息入口、收藏入口、设置入口、重新诊断。
- **进入方式**：底部 Tab。**关键交互**：看报表；进各子页。

### 5.2 消息（私信列表）
- **目标**：管理私信会话，提示未回复上限。
- **核心元素**：会话列表（头像/最后消息/未回复上限提示）、红点。
- **进入方式**：个人中心 → 消息。**关键交互**：进会话；从用户主页发起新私信。

### 5.3 私信会话
- **目标**：与单用户聊天。
- **核心元素**：气泡对话、输入框、发送、未回复上限提示（对方未回复前最多 2 条）、可选翻译。
- **进入方式**：消息列表 / 用户主页私信。**关键交互**：发消息（受 ≤2 限制）；对方回复后解除上限。

### 5.4 导入（书籍 / 音频 / 文章）
- **目标**：导入个人材料，扩展生词来源。
- **核心元素**：导入方式（本地文件/粘贴/链接）、类型选择（书籍/音频/文章）、解析中状态、进入阅读/听书。
- **进入方式**：个人中心 → 导入。**关键交互**：选类型 → 导入 → 阅读/听书模式。

### 5.5 阅读 / 听书
- **目标**：阅读/听书，长按加生词，累计时长。
- **核心元素**：正文（音频：字幕随语音高亮）、全局点读/跟读、长按选词 → 加入生词本、进度/时长。
- **进入方式**：导入完成。**关键交互**：长按选词加生词；听书时长计入个人中心。

### 5.6 学习分层（生词 / 运用 / 掌握）
- **目标**：看掌握进度与分层，进入各层练习。
- **核心元素**：三栏/分段（生词本/运用层/掌握层）、A-Z + 同根聚合、计数、进入闯关/运用。
- **进入方式**：收藏与集合 → 学习分层。**关键交互**：进生词本闯关；进运用层造句。

### 5.7 生词本闯关
- **目标**：生词+错题合并闯关，连续对 5 次（同一题型，不做轮替）升运用层。
- **核心元素**：闯关卡（选词义/听写/拼写之一种，沿用上次题型不做轮替）、进度（连续对 x/5）、遗忘曲线排程提示、即时反馈。
- **进入方式**：学习分层 → 生词本。**关键交互**：作答；过关升层；错回流错题本。

### 5.8 运用层（造句 + AI 校验）
- **目标**：用生词造 2 句，AI 查语法/句义，正确入掌握层。
- **核心元素**：目标词、造句输入框、AI 校验反馈（语法/句义）、进度（造 x/2）、1/3/7/14/30 天复现提示。
- **进入方式**：学习分层 → 运用层。**关键交互**：造句 → AI 校验 → 正确入掌握。

### 5.9 收藏列表
- **目标**：看所有收藏（词/句/课）。
- **核心元素**：分类标签（词/句/课）、列表、移入集合。
- **进入方式**：收藏与集合。**关键交互**：点进详情；加入/新建集合。

### 5.10 集合详情
- **目标**：看集合内容，一键学习。
- **核心元素**：集合内条目、编辑/删除、一键作为一日任务。
- **进入方式**：收藏与集合 → 集合。**关键交互**：一键学习 → 学习流程；编辑。

### 5.11 设置
- **目标**：个性化与偏好。
- **核心元素**：中文辅助开关、语速、口音、深色模式、通知提醒、关于。
- **进入方式**：个人中心 → 设置。**关键交互**：切换开关即时生效（作用于全局发声/辅助）。

## 附录 A：Linguabase 字段映射与降级策略表

| 卡片类型 | Linguabase 源字段 | 前端呈现方式 | 字段缺失时的降级策略 |
|---|---|---|---|
| 字母/音标卡 | char, ipa, audio_path | 大字展示 + IPA + 点击播放音频 | audio_path 为空 → 隐藏发音按钮，不显示报错；ipa 为空 → 不展示音标行 |
| 单词卡 | word, definition_zh, example_en, example_zh, audio_path, word_hint | 单词+中文释义为主；例句默认折叠；点击展开 | definition_zh 为空 → 降级显示英文释义；example_en 为空 → 隐藏例句折叠区 |
| 句型卡 | pattern, structure_note, sample_sentences[] | 句型公式高亮 + 1 个最简例句 | structure_note 为空 → 仅展示例句；sample_sentences 为空 → 展示句型公式 |
| 练习题 | quiz_question, quiz_options, quiz_answer | 选择题/连线题 | 该知识点无 quiz 字段 → 跳过练习直接标记完成 |
| 知识卡排序 | difficulty_level, frequency_rank | 按 difficulty 升序 + frequency 降序排列 | 排序字段为空 → 按 Linguabase 原始顺序展示 |

## 附录 B：离线支持矩阵

| 离线等级 | 页面 | 离线行为说明 |
|---|---|---|
| ✅ 完全离线可用 | 字母卡、音标卡、单词卡、句型卡 | 本地缓存 Linguabase 数据包，离线可正常浏览、点读（音频需预缓存）、收藏 |
| ✅ 完全离线可用 | 知识卡（学习流程内） | 本地缓存 Linguabase 数据包，离线可正常渲染卡片流 |
| ✅ 完全离线可用 | 复习页 | 本地缓存最近 7 天复习队列数据，离线可正常闯关 |
| ✅ 完全离线可用 | 错题本 | 本地缓存最近 7 天错题记录，离线可查看与复习 |
| ⚠️ 部分离线 | 今日数据页（个人中心） | 仅展示本地记录的完成数与连续天数，不上传服务器；联网后自动同步 |
| ⚠️ 部分离线 | 成就墙 | 可查看已解锁成就（本地缓存）；新成就不触发弹窗，联网后补弹 |
| ⚠️ 部分离线 | 设置页 | 可修改本地偏好（语速/深色模式等），联网后同步到云端 |
| ❌ 必须联网 | 登录/注册页 | 需实时验证账号 |
| ❌ 必须联网 | 协议页 | 需实时拉取最新协议全文 |
| ❌ 必须联网 | 更新提示页 | 需实时检查 Linguabase 数据包版本 |
| ❌ 首次 / ✅ 重诊断 | 诊断测试（水平测试） | 首次须联网校验防篡改；每 7 天重诊断使用本地 Linguabase 题目，可离线进行 |
| ❌ 必须联网 | 搜索/AI 问答 | 搜索词库与 AI 对话均需联网 |
| ❌ 必须联网 | 笔记流/笔记详情/发布笔记 | UGC 内容需实时联网 |
| ❌ 必须联网 | 导入（书籍/音频/文章） | 文件解析需服务端处理 |
| ❌ 必须联网 | 私信会话 | 实时通信需联网 |

**通用离线规则**：
- 离线时进入❌必须联网的页面，显示友好提示页：「信号迷路了，连上网继续学！」并提供「返回首页」按钮。
- 离线时用户的学习进度本地暂存，联网后自动同步，不丢失。
- Linguabase 数据包在首次联网时全量下载到本地，后续仅增量更新。
