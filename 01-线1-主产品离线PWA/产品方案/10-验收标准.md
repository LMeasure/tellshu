# 验收标准（Acceptance Criteria）v0.1 —「述树」零基础英语

> 前置：MVP 开发顺序 v0.1 已确认。本步是 10 步产品方案的最后一步，把功能/体验/性能/适配落成**可勾选的验收清单**，并对接各 Phase 退出标准（09 §1-§4）与 PRD 指标（01 §3）。
>
> 用法：每条带 `[ ]` 勾选框；标注所属 **Phase（0/1/2）** 与 **维度（功能/体验/性能/适配）**。MVP 验收 = Phase 0+1+2 全部达标。

---

## 0. 验收总原则

1. **零基础可独立完成**：不依赖任何英语基础，全程中文辅助可走通。
2. **离线优先**：学习相关功能断网可用，不出现技术报错（04 附录 B）。
3. **三态齐备**：每个列表/详情/流程页都必须有空/加载/错误态（05 §0.3）。
4. **指标达标**：以 PRD §3 北极星（7 日留存）与关键指标为定量门槛。

---

## 1. 功能验收（逐功能勾选）

### 1.1 核心闭环（PRD §4）
- [ ] **P0** 启动→登录（游客可进）→诊断 5 题梯度跑通，生成每日任务与起始 topic_id（06 §3.2）。
- [ ] **P0** 今日任务点进学习流程：知识卡→单词/句型卡→跟读→练习→练习结果，流程不中断。
- [ ] **P0** 练习即时对错反馈；全对发奖励、有错自动入错题本（06 §3.3 / 05 §2.5）。
- [ ] **P1** 每 7 天重诊断提醒并刷新每日任务节奏（IA §2 / 05 §1.2）。

### 1.2 十项必备功能（PRD §5）
- [ ] **P0** 入门诊断：按 Linguabase `difficulty_level` 分梯度抽 5 题，兜底规则生效（04 §1.2）。
- [ ] **P0** 学习路径：字母→音标→词汇→句型→对话节点可见，点节点回看知识卡（05 §2.3）。
- [ ] **P0** 发现页：搜索 + 筛选 chips（主题/难度/场景/时长/技能）+ 双列卡片网格（05 §2.1）。
- [ ] **P0** 学习卡片：英文+中文+音标+图片+例句+`word_hint`+点读+慢速+收藏（04 附录 A）。
- [ ] **P0** 练习：选择/配对/填空/排序/听写/跟读六类可用，即时反馈（05 §2.4）。
- [ ] **P1** 复习：间隔重复队列 + 错题本 + 每日复习任务（06 §4 / 05 §6）。
- [ ] **P0** 收藏与集合：长按收藏、建集合（如旅行英语），集合可「作为一日任务」（05 §8）。
- [ ] **P2** AI 助手：解释单词/纠错/生成例句/对话陪练；搜索切 AI 模式 + 上下文问 AI（05 §2.2 / 08 §6）。
- [ ] **P0** 个人中心：进度/连续天数/每日目标/提醒可见（05 §2.9）。
- [ ] **P0** 设置：中文辅助开关/语速/口音/深色模式生效（06 §8.2）。

### 1.3 增强功能（历次迭代）
- [ ] **P1** 跟读 ASR：单词/句子可录音评分+纠错（参考百度翻译），Phase 1 粗评分、Phase 2 音素级（08 §5）。
- [ ] **P1** 每日单词量：个人中心展示当日从生词本→运用层的词数（06 §7.3）。
- [x] **P1** 导入：书籍/音频/文章可导入；阅读/听书中长按选词自动加生词本（05 §5.5 / IA §5）。已落地：本地 .txt 上传、文本粘贴、录音转写三种来源，阅读器点/长按单词 → 底部弹层 → 加入生词本。
- [ ] **P1** 生词本闯关三阶段：选词义→听写→拼写，连续对 5 次（同一题型不做轮替），单词错落均匀分布（06 §4.1）。
- [ ] **P1** 分层掌握：生词本→闯关层→运用层（造 2 句+AI 校验）→掌握层（A-Z+同根聚合）（06 §4）。
- [ ] **P1** 遗忘曲线：加入即 10min/1h 排程；运用层 1/3/7/14/30 天复现；错词回流（06 §4）。
- [ ] **P2** 笔记流：自己/他人笔记与感想，点赞/评论/回复 + 评论中英翻译（05 §5 / 08 §3.3）。
- [ ] **P2** 关注 + 私信：可关注作者；私信对方未回复前最多 2 条（06 §6.4-6.5）。
- [ ] **P1** 个人中心可视化：微信读书式，每日掌握单词量 + 阅读时长（含听书 n小时m分钟）+ 周/月/年/总进度表（06 §7.3）。
- [ ] **P0/P1** 离线：学习相关页 ✅完全离线；个人中心/成就/设置 ⚠️部分离线；登录/诊断首检/搜索AI/笔记/导入/私信 ❌OfflineGate（04 附录 B）。

## 2. 体验验收（零基础友好）

- [ ] **零门槛**：首次打开无需英语即可开始；所有英文配中文释义（PRD §7）。
- [ ] **即时反馈**：单卡/单练完成有音效+微动效；答对/错立即高亮（05 §2.5）。
- [ ] **成就不骚扰**：完成度≥80% 每日仅 1 次祝贺弹窗；里程碑 3/7/14/30 合并徽章，不叠加；3 秒或无操作自动消失（06 §8.1）。
- [ ] **情感化**：连续天数、进度环、徽章正向激励，无排行榜压力（PRD §7）。
- [ ] **碎片化**：单段今日任务 ≤5 分钟可完成（PRD §3/§7）。
- [ ] **手势一致**：卡片点击详情/长按收藏/右滑已掌握/左滑错题，全局统一（IA §4 / 05 §0.3）。
- [ ] **降级无半成品**：Linguabase 字段缺失静默降级（隐藏发音/不展示音标/英文释义兜底），绝无报错或空白（04 附录 A）。

---

## 3. 性能验收

- [ ] **首屏**：冷启动首屏 ≤2s（375px 中端机）；卡片列表滚动 60fps。
- [ ] **音频**：发音/点读点击后 ≤300ms 出声；慢速切换无卡顿。
- [ ] **包体积**：Linguabase 首包 5–20MB，音频懒加载，首次下载不阻塞可学（08 §3.4）。
- [ ] **本地读写**：生词本/复习队列查询（按 next_review/layer） ≤100ms（Dexie 索引，08 §3.2）。
- [ ] **离线响应**：断网进入 ✅页瞬时可用；进入 ❌页 1s 内显示 OfflineGate 友好提示（04 附录 B）。
- [ ] **同步**：联网后 dirty 数据增量上传成功，无丢失、无重复（08 §3.2/§7）。

---

## 4. 适配验收

- [ ] **375px 优先**：在 375px 视口真机/模拟器视觉通过；更大屏居中留白不破版（组件树 §0）。
- [ ] **触摸目标**：可点元素 ≥44px；底部 Tab 适配 `safe-area-inset-bottom`。
- [ ] **深色模式**：设置切换 light/dark/system 全组件生效，主色/强调色对比达标（组件树 §0）。
- [ ] **三态齐备**：列表/详情/流程页均验证 空态 / 加载骨架 / 错误重试 三态（05 §0.3）。
- [ ] **绿色多巴胺**：主色 ≤2 + 强调色 1，圆角卡片 + 柔和阴影 + 标签胶囊 + 大标题符合规范（PRD §8）。
- [ ] **可访问性**：基本对比度达标，发音按钮有文字/图标双标识。

## 6. 定量指标门槛（PRD §3，MVP 对外推广前）

| 指标 | 门槛 | 测量方式 |
|---|---|---|
| 7 日留存（北极星） | ≥20% | 埋点 cohort |
| 次日留存 | ≥40% | 埋点 |
| 今日任务完成率 | ≥60% | 每日 completion_pct（06 §3.3） |
| 日均学习时长 | 5–10 分钟 | 会话时长 |
| 跟读完成率 | ≥50% | 跟读提交/触发比 |
| 连续天数 median | ≥3 天 | streak 分布 |

> Phase 1 准出参考：5 人零基础可用性测试中，今日任务完成率≥60%、跟读完成率≥50%（09 §6）。

---

## 7. 验收方法

- **真机**：iPhone SE(375px)/主流 Android，Safari/Chrome，深浅色各测一遍。
- **断网**：开飞行模式验证 ✅/⚠️/❌ 三档行为（04 附录 B）。
- **可用性**：每 Phase 末 5 名零基础用户任务测试（诊断→学→练→复习→收藏→设置）。
- **埋点**：登录即埋 retention/completion/readaloud 事件，验证 §6 门槛。
- **降级**：人为删 Linguabase 字段，验证静默降级无报错（04 附录 A）。
