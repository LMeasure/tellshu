# 数据接入管线 · 述树 ← Linguabase（v0.1）

> 配套代码：`scripts/linguabase_ingest.py`（抽取/映射）、`src/data/repository.ts`（加载）、`src/lib/speech.ts`（运行时发音）、`src/components/learning/WordCard.tsx`（渲染+降级）。
> 原则：**不创造虚拟数据**——只产出从真实 Linguabase 字段抽取的内容，缺失字段一律留空。

> 另见 **13-OpenEtymology内容层.md**：中文释义 / 音标 / 双语例句 / 词源 / 词根词缀的真实来源，由 `scripts/openetymology_ingest.py` 解析五个词本 EPUB 得到，按词本分片输出（`index.json` + `books/*.json`，共 22,791 条），是述树当前的主力内容层。

## 1. 为什么需要这条管线

Linguabase（CC0，IDEA.org）是**英语词义关系图谱**，不是教材。它提供真实词表、熟悉度排序、英文释义、关联词、反义词、同根词，但**没有**中文释义、音标、音频、字母/句型教学内容和诊断题库。本管线把前者真实抽取成述树 `ContentWord` 形状，缺口用真实方式补齐（运行时发音、外部词典、分桶难度），绝不虚构。

## 2. 端到端流程

**主力路径（OpenEtymology 内容层，见 13）— 按词本分片、首屏仅 ~1KB：**

```
OpenEtymology 五个词本 EPUB (CET4/CET6/TEM8/TOEFL/GRE8000)
        │  scripts/openetymology_ingest.py  (zipfile + BeautifulSoup 真实解析)
        ▼
public/data/linguabase/index.json          # 极小索引（~1KB）：词本清单 + 每本路径/词数（首屏加载）
public/data/linguabase/books/CET4.json …   # 单本词包（2.8-10.8MB，进入该词本时按需懒加载）
public/data/linguabase/manifest.json       # 人类可读 provenance（字段状态/许可）
        │  vite 构建时拷贝到 dist/；运行时浏览器按需 fetch
        ▼
src/data/repository.ts
   ├─ getBookIndex()  →  仅 fetch index.json（首屏）
   └─ getWords(bookId)→  按 book 懒加载 books/<id>.json（带缓存）
        │
        ▼
页面/组件 (Search 词本切换 / LearningFlow ?book= / WordCard)
   └─ WordCard 渲染真实 IPA/中文/双语例句/词源/词根词缀；audio 走 Web Speech API 合成
```

> **首屏加速原理**：旧方案单个 `words.json` 整包 19MB 一次性加载；分片后首屏只拉 `index.json`（755B），只有用户进入某个词本（如 CET4，5.8MB）才加载对应分片，且 `getWords()` 不再跨词本去重合并，按需即可。

**增强路径（Linguabase 关系网络，可选）— 仅补全关系字段，不替换内容层：**

```
Linguabase core parquet (vocabulary/definitions/associations/antonyms/word_families)
        │  scripts/openetymology_ingest.py --linguabase-data-dir <目录>  （按 headword 合并）
        ▼
在每本 ContentWord 上补 frequency_rank / related / antonyms / relatives
```

## 3. 字段映射（真实来源）

| 输出字段 | 来源 | 说明 |
|---|---|---|
| `word` | `vocabulary.word` | 主键 |
| `frequency_rank` | `vocabulary.core_rank` | 1=最熟悉 |
| `difficulty_level` | 派生 | `core_rank ≤ 100000` → **L2 基础词**；否则 **L3 进阶**；L1 字母级属教材层，本管线不产 |
| `definition_en` | `definitions.definition` | 去 `{braces}` 斜体标记的纯文本 |
| `example_en` | `definitions.definition` 首个 `{…}` | 真实用例（括号即 Linguabase 约定的斜体用例） |
| `related` | `associations.associates` | 取前 8，**裁剪到 core 内**（保证可学） |
| `antonyms` | `antonyms.opposites` | 解析 `term:rating`，取强度 ≥ 6 的前 6 |
| `relatives` | `word_families.relatives` | 取前 8，**裁剪到 core 内** |
| `ipa` | espeak-ng（可选） | 系统装有则离线真实生成美式 IPA；否则 `null` |
| `audio_path` | — | 始终 `null`；由前端 Web Speech API 实时合成（真实音频） |
| `definition_zh` / `example_zh` | `--zh-dict` 外部词典 | 缺则 `null`，按 04 附录 A 降级显示英文 |
| `word_hint` / `root` | — | `null`（仅在可简单拆分时后续补充） |
| `topic_id` | 派生 | `freq-basic` / `freq-advanced`（真实主题聚类后续由 `topics` 表增强） |

## 4. 用法

```bash
# 自动在 /root/uploads、./linguabase_data 等常见目录找数据
python3 scripts/linguabase_ingest.py

# 指定数据目录，抽取前 2000 个最高频词
python3 scripts/linguabase_ingest.py --data-dir /path/to/linguabase --top 2000

# 顺带灌入中文释义（合规 EN-ZH 词典，TSV：word\t中文）
python3 scripts/linguabase_ingest.py --data-dir /path/to/linguabase --zh-dict dict.tsv

# 仅校验映射方案、不产出词（无数据或显式 --validate）
python3 scripts/linguabase_ingest.py --validate
```

环境要求：Python 3.11 + `pyarrow`（已装 23.0）。`espeak-ng` 可选（沙箱当前未装，故 IPA 为 pending）。

## 5. 校验结果（已执行）

- **校验模式**：未放 parquet 时仅写出 `manifest.json`（`status:"pending_data"`），**不写任何词**，遵守不编造原则。
- **端到端**（用 README 真实示例值 `elephant/cold/electric` 建临时夹具，跑通后立即删除）：
  - `definition_en` 正确去除花括号；`example_en` 取自首个 `{用例}`；
  - `antonyms` 正确解析 `cold → hot:7, warm:7, boiling:6`；
  - `difficulty_level` 由 `core_rank` 正确分桶；缺失字段均为 `null`；
  - 关联/同根词因夹具词不在 core 集合内被裁剪为空（符合预期）。
- **构建/服务**：`npm run build` 通过；vite 将 `public/data/linguabase/words.json` 送到 `dist/data/linguabase/`，前端 `fetch('/data/linguabase/words.json')` 路径吻合（已验证，随后清空假词）。
