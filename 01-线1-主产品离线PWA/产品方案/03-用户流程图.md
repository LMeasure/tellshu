# 用户流程图（User Flow）v0.2 —「述树」零基础英语

> 前置：IA v0.4 已定稿。本步把核心闭环与关键分支画成流程，供后续页面清单/组件状态/开发顺序使用。
> 约定：◆ 入口页  ▶ 动作/跳转  ◆ 决策(是/否)  ⏹ 终止/落库

---

## 0. 知识卡从哪来（先澄清）

知识卡是**学习路径节点 / 课程配套的内容单元**，内容由 Linguabase 下载包驱动，前端按字段自动渲染为交互式卡片流（无视频、无人工编辑）：
- 诊断生成「每日任务」→ 自动带出当日节点对应的 Linguabase 数据记录 → 渲染为知识卡；
- 发现页课程 = 若干节点 + 其知识卡，进学习流程依次展示；
- 首页「学习路径总览」点节点可回看其知识卡；
- 字段缺失时静默降级（如 audio_path 为空则隐藏发音按钮，不显示报错或占位符）；
- 卡片排序按 Linguabase 中 difficulty_level + frequency_rank 字段动态排序，确保零基础用户先看到最简单、最高频的内容；
- 单张卡片因数据异常无法渲染时，静默跳过并记录日志，绝不让用户看到空白页或错误码。
- 未来：导入文章后 AI 生成情境知识卡（MVP 不做）。

> 学习流程结构固定为：**知识卡 → 单词/句型卡 → 听音跟读 → 练习 → 练习结果**。

## 1. 核心学习闭环（主流程）

```
[启动] → 登录 → ◆诊断测试（每7天一次）
        ↓
   生成学习计划 + 每日任务
        ↓
◆首页·今日任务卡（连续天数/进度/奖励横条）
        ▶ 点击「开始」
        ↓
◆学习流程（共享容器）
   ├─ ① 知识卡（Linguabase 数据驱动，自动渲染）
   ├─ ② 单词/句型卡（点读/慢速/中文/word_hint/收藏）
   ├─ ③ 听音跟读（ASR 评分+纠错）
   ├─ ④ 练习（选/配对/填空/排序/听写/跟读）
   └─ ⑤ 练习结果
        ↓
   ◆决策：是否全对？
   ├─ 是 → 发奖励 → ◆决策：当日学习计划完成度 ≥80%？
   │        ├─ 是 → 触发 1 次祝贺弹窗（每日仅 1 次） → ◆决策：连续天数达里程碑(3/7/14/30)？
   │        │        ├─ 是 → 合并展示徽章弹窗 → ⏹ 回首页/下一任务
   │        │        └─ 否 → ⏹ 回首页/下一任务
   │        └─ 否 → 仅即时音效+微动效（不弹窗） → ⏹ 回首页/下一任务
   └─ 否 → 错题自动入「错题本」 → 复习 Tab 红点提醒 → ◆复习
```

## 2. 诊断 → 每日任务（节奏引擎）

```
首次 / 每7天到点提醒
   ↓
◆诊断测试（字母 / 发音 / 词汇量 小测）
   ↓
评估当前等级（零基础→路径节点）
   ↓
生成学习计划（路径节奏：字母→音标→词汇→句型→对话）
   ↓
拆解出「每日任务」= 当日路径节点集合（每节点含：知识卡+卡片+练习）
   ↓
写入 个人中心 / 首页今日任务卡
```

## 3. 首页搜索 / AI（搜索项模式切换）

```
◆首页顶部搜索
   ▼ 模式切换
   ├─ [搜索] → 查词 / 课程 / 笔记流 → 结果页 → 进入对应详情
   └─ [AI 问答] → ◆AI 对话（解释单词 / 纠错 / 生成例句 / 陪练）
                  → 上下文「问 AI」也可从卡片/跟读/练习页唤起
```

---

## 4. 发现页（卡片流 + 笔记流）

### 4.1 课程/词单卡片流
```
◆发现
   ├─ 顶部搜索 + 筛选 chips（主题/难度/场景/时长/技能）
   ├─ 双列卡片网格
   │     ▶ 点击卡片 → ◆课程详情（大图/标签/简介/收藏/开始学习）
   │           ▶ 开始学习 → ◆学习流程
   └─ 卡片手势：点击=详情 / 长按=收藏 / 右滑=已掌握 / 左滑=错题
```

### 4.2 笔记流（小红书式轻量社交）
```
◆发现 → 「笔记」tab
   ├─ 浏览笔记流（自己/他人）
   │     ▶ 点赞（toggle）
   │     ▶ 点击卡片 → ◆笔记详情
   │           ├─ 评论 / 回复（评论支持中英翻译）
   │           ├─ 作者主页 → 关注（toggle）
   │           └─ 作者主页 → 私信
   ├─ 发布笔记（◆编辑页：图文+标签）
   └─ 私信规则：对方未回复前最多发 2 条（防骚扰上限），回复后解除
```

## 5. 导入阅读 / 听书 → 生词飞轮

```
◆我的 → 导入（书籍 / 音频 / 文章）
   ↓
◆阅读 / 听书模式（音频：字幕随语音高亮）
   ▼ 长按选中任意单词
   ↓
自动加入「生词本」
   ↓
生词本在「闯关层」持续重现（见 §6）
```
> 阅读时长 / 听书时长（n 小时 m 分钟）计入个人中心可视化进度。

## 6. 分层掌握（复习引擎状态机）

```
           加入即排程：10分钟、1小时
           ┌──────────────────────┐
生词本 ─────┤                      ├──┐
错题本 ─────┤   闯关层（合并出题）   │  │
           └──────────────────────┘  │
                      │              │
              连续对5次（同一题型）？    │ 否→回流错题本
              ├─ 否 → 继续闯关       │
              └─ 是 → 升 运用层 ─────┘
                       │
              运用层：用该词造 2 句
                       ▼
              AI 查语法 + 句义 正确？
              ├─ 否 → 回流错题本
              └─ 是 → 掌握层（A-Z 排序、同根聚合）
                       │
              运用层在 第 1/3/7/14/30 天 各复现≥1次
```

## 7. 复习


## 8. 收藏 / 集合

```
任意卡片：长按=收藏 / 右滑=已掌握 / 左滑=错题
   ↓
◆收藏与集合
   ├─ 收藏列表（词/句/课）
   ├─ 集合（自建：旅行英语/餐厅点餐…）
   │     └─ 集合可「作为一日任务」一键学习（为「我的词单」埋点）
   └─ 学习分层（生词/运用/掌握，见 §6）
```

---

## 9. 设置 / 重诊断

```
◆我的 → 设置（中文辅助开关 / 语速 / 口音 / 深色模式）
◆个人中心 → 重新诊断（每7天自动触发，也可手动）
```

## 10. 全局手势与状态（所有列表/详情/流程页复用）

| 手势 / 状态 | 行为 |
|---|---|
| 长按卡片 | 收藏 |
| 右滑卡片 | 标记为已掌握（升层） |
| 左滑卡片 | 加入错题本 |
| 空状态 | 引导式插画 + 一键行动（如「去发现」「导入文章」） |
| 加载 | 骨架屏（卡片/列表占位） |
| 错误 | 错误态 + 重试按钮 |
| 全局点读 | 任意英文/例句可点读、慢速、逐词点读 |
| 全局跟读 | 任意单词/句子可跟读，ASR 评分+纠错 |
