# 数据模型（Data Model）v0.1 —「述树」零基础英语

> 前置：每页组件和状态 v0.2 已确认。本步把各页数据流字段落地为实体、字段与关系，含 Linguabase 字段映射、本地优先存储与云端同步（mock→Supabase/Firebase）方案，以及分层掌握所需的 `layer / root / consecutive_correct / next_review` 等核心字段。
>
> 目标读者：后续前端（React+Tailwind+shadcn/ui，375px 优先）与后端（Supabase/Firebase）实现者。

## 0. 存储与同步总策略

| 数据类别 | 来源 | 存储 | 离线 | 说明 |
|---|---|---|---|---|
| 内容（字母/音标/单词/句型/诊断题） | `[Linguabase]` 下载包（只读） | 本地全量缓存 + 云端只读镜像 | ✅ 完全离线 | 首次联网全量下载，后续增量更新 |
| 学习进度/分层/复习/收藏/设置/阅读时长 | `[本地生成]` | 本地优先（IndexedDB/MMKV） | ✅ 完全离线 | 联网后增量同步云端 |
| 社交 UGC（笔记/评论/关注/私信/导入解析） | `[联网]` | 云端（Supabase/Firebase） | ❌ 走 OfflineGate | 强依赖实时网络 |

**三层数据形态（MVP 落地顺序）**
1. **Phase 0（纯 mock）**：全部用本地 JSON mock，不接任何后端，验证交互。
2. **Phase 1（本地持久化）**：学习数据落本地存储（IndexedDB + Zustand persist / RN MMKV），社交数据用 mock 假数据。
3. **Phase 2（Supabase/Firebase）**：本地数据同步云端；社交 UGC 切真后端；Linguabase 包走 CDN/对象存储拉取。

**数据访问约定（贯穿前端）**
- 读内容：`useContent(id)` → 优先本地 Linguabase 缓存，未命中且离线则静默降级（见 04 附录 A）。
- 读写学习态：`useLearningState()` → 本地存储，带 `dirty` 标记，联网后 `sync()`。
- 社交：`useSocial()` → 联网请求，离线走 `OfflineGate`。

## 1. 实体关系总览（ERD）

```
[Linguabase 内容源 - 只读]
content_topic 1──* content_letter / content_word / content_pattern
content_word  *──1 content_topic
content_word  ──(root) 同根聚合（相同 root 相邻展示）
content_diagnostic(按 difficulty_level 标记的题目池)

[用户与计划 - 本地]
user 1──1 diagnose_result(每7天一次)
user 1──* daily_plan(每日一条) 1──* daily_task_item
user 1──1 settings

[分层掌握 - 本地核心]
user 1──* vocab(content_word_id 外键)
vocab.layer ∈ {new, practice, apply, mastered}
vocab.next_review ← srs_schedule(vocab)

[收藏与集合 - 本地]
user 1──* favorite 1──* collection_item ──* collection
collection 1──* collection_item
collection ──(可选) 作为一日任务 → daily_plan

[社交 UGC - 联网]
user 1──* note 1──* note_like
note 1──* comment(支持 parent 回复) 1──1 comment_translation
user 1──* follow(follower/followee)
user 1──* dm(sender/receiver, ≤2 未回复上限)

[导入与阅读 - 解析联网/内容本地]
user 1──* import_job 1──* reading_session 1──1 reading_time_aggregate(按日)
reading_session ── 长按选词 ──▶ favorite(vocab 生词)

[成就 - 本地]
user 1──* achievement
```

## 2. 内容实体（来源：Linguabase 下载包，只读）

### 2.1 `content_topic`（路径节点）
| 字段 | 类型 | 说明 |
|---|---|---|
| topic_id | string (PK) | 节点唯一 ID，诊断结果写入此为起始点 |
| node_type | enum | `letter` / `ipa` / `word` / `pattern` / `dialogue` |
| name | string | 节点名（中文，如「字母 A」/「单元音」） |
| order_index | int | 路径顺序 |
| difficulty_level | int(1-3) | 难度梯度（诊断与排序用） |
| prerequisite_topic_id | string? | 前置节点 |
| content_refs | string[] | 关联的 letter/word/pattern id 列表 |

### 2.2 `content_letter`（字母/音标卡）
| 字段 | 类型 | Linguabase 源 | 缺失降级 |
|---|---|---|---|
| char | string (PK) | `char` | — |
| ipa | string? | `ipa` | 为空不展示音标行 |
| audio_path | string? | `audio_path` | 为空隐藏发音按钮，不报错 |

### 2.3 `content_word`（单词卡 / 主体内容）
| 字段 | 类型 | Linguabase 源 | 缺失降级 |
|---|---|---|---|
| word | string (PK) | `word` | — |
| ipa | string? | `ipa` | 不展示音标行 |
| definition_zh | string? | `definition_zh` | 为空降级显示英文释义 |
| example_en | string? | `example_en` | 为空隐藏例句折叠区 |
| example_zh | string? | `example_zh` | 同上 |
| audio_path | string? | `audio_path` | 为空隐藏发音按钮 |
| word_hint | string? | `word_hint` | 为空不展示助记提示 |
| root | string? | `root`（新增，同根聚合用） | 为空不参与同根聚合 |
| difficulty_level | int(1-3) | `difficulty_level` | 排序时按原始顺序 |
| frequency_rank | int? | `frequency_rank` | 排序时按原始顺序 |
| topic_id | string | `topic_id` | — |
| quiz_question | string? | `quiz_question` | 无 quiz → 跳过练习直接标记完成 |
| quiz_options | string[]? | `quiz_options` | 同上 |
| quiz_answer | string? | `quiz_answer` | 同上 |

> 排序规则：`ORDER BY difficulty_level ASC, frequency_rank DESC`（零基础先看最简单最高频）；排序字段为空则保持 Linguabase 原始顺序。

### 2.4 `content_pattern`（句型卡）
| 字段 | 类型 | Linguabase 源 | 缺失降级 |
|---|---|---|---|
| pattern | string (PK) | `pattern` | — |
| structure_note | string? | `structure_note` | 为空仅展示例句 |
| sample_sentences | json[]? | `sample_sentences` | 为空仅展示句型公式 |

### 2.5 `content_diagnostic`（诊断题库，按难度梯度）
| 字段 | 类型 | 说明 |
|---|---|---|
| quiz_id | string (PK) | 题目 ID |
| difficulty_level | int(1-3) | 1=字母辨识 / 2=高频词认读 / 3=句型理解 |
| question | string | 题干 |
| options | string[] | 选项 |
| answer | string | 正确项 |
| maps_to_topic_id | string | 答对则推荐起点 topic_id |

> 诊断抽题：第 1-2 题 `difficulty=1`、第 3-4 题 `difficulty=2`、第 5 题 `difficulty=3`；前 2 题错 ≥1 → 终止并推荐 `difficulty=1` 起点；全对 → `difficulty=3`；中间 → `difficulty=2`。

## 4. 分层掌握实体（本地核心复习引擎）

### 4.1 `vocab`（生词本 / 闯关层 / 运用层 / 掌握层 的统一表）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string (PK) | |
| user_id | string (FK) | |
| content_word_id | string (FK→content_word) | 关联的单词 |
| layer | enum | `new`(生词本) / `practice`(闯关层) / `apply`(运用层) / `mastered`(掌握层) |
| root | string? | 同根聚合键（冗余自 content_word.root，便于 A-Z+同根排序） |
| consecutive_correct | int | **闯关层**：连续答对次数（同一题型），满 5 升 `apply` |
| last_quiz_form | enum? | 上次闯关题型（选词义/听写/拼写），**仅作记录用**；下次闯关沿用同一题型，不做轮替 |
| in_wrong_pool | bool | 是否在错题本（与闯关层合并出题） |
| wrong_count | int | 累计错次 |
| next_review | datetime | **SRS 下次复习时间**（10min/1h/1d/3d/7d/14d/30d） |
| added_at | datetime | 加入生词本时间（排程 10min/1h 首复习） |
| last_seen | datetime | 最近出现 |
| mastered_at | datetime? | 升掌握层时间 |
| srs_box | int(1-5) | 间隔重复盒子（1=生疏…5=牢固），与 layer 协同 |

**状态机（与 03 流程图 §6 一致）**
```
new(生词本) ──连续对5次(consecutive_correct=5, 同一题型, next_review 按 10min/1h 排程)──▶ practice(闯关层)
practice ──造2句+AI校验语法句义正确──▶ apply(运用层)
apply ──第1/3/7/14/30天各复现≥1次──▶ mastered(掌握层, A-Z+同根排序展示)
wrong_pool(错题) ──合并进 practice 闯关层, 反复出错自动回流──┐
mastered ──遗忘复现失败──▶ practice（闭环）
```

### 4.2 `review_queue`（派生 / 可计算）
- 由 `vocab WHERE next_review <= now` 实时计算，无需独立表；离线取「最近 7 天」本地缓存子集。
- 出题排序：生词本与错题本**合并同一闯关层**，不同单词错落均匀分布（按 `added_at` 交错 + 随机洗牌），避免连片疲劳。

### 4.3 `apply_attempt`（运用层造句记录）
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string (PK) | |
| vocab_id | string (FK) | |
| sentence_1 | string | 用户/AI 给出的句子 1 |
| sentence_2 | string | 句子 2 |
| grammar_ok | bool | AI 校验语法 |
| meaning_ok | bool | AI 校验句义 |
| checked_at | datetime | |
| passed | bool | 两句子均通过 → 升 mastered |

> 离线策略：运用层 AI 校验离线时缓存最近结果、禁用新校验（见 05 §2.6）。

## 8. 成就与设置（本地）

### 8.1 `achievement`
| 字段 | 类型 | 说明 |
|---|---|---|
| id | string (PK) | |
| user_id | string (FK) | |
| type | enum | `daily_complete`(完成度≥80%) / `streak`(连续天数里程碑 3/7/14/30) |
| key | string | 具体成就键（如 `streak_7`） |
| unlocked_at | datetime | |
| shown | bool | 是否已弹窗（每日去重，见下） |

**成就弹窗去重（与 04 §2.5 / 05 §2.5 一致）**
- 同一天：`daily_complete` 与 `streak` 同时触发 → 按优先级 **里程碑徽章 > 每日完成度** 合并为 1 张卡片（上徽章 + 下祝贺文案），仅弹 1 次。
- 触发条件：完成度 ≥80% 每日 1 次；连续天数 3/7/14/30 里程碑额外 1 次（合并展示）。
- 关闭：点「收下」或 3 秒无操作自动消失。
- 单卡片/单练习完成：仅即时音效 + 微动效，不弹窗。

## 9. Linguabase 字段映射汇总（与 04 附录 A 对齐）

| 前端卡片 | Linguabase 源字段 | 落库字段 | 缺失降级 |
|---|---|---|---|
| 字母/音标卡 | `char, ipa, audio_path` | content_letter | audio_path 空→隐藏发音；ipa 空→不展示音标行 |
| 单词卡 | `word, definition_zh, example_*, audio_path, word_hint, root, difficulty_level, frequency_rank` | content_word | definition_zh 空→英文释义；example 空→隐藏例句区；audio 空→隐藏发音；word_hint 空→不展示 |
| 句型卡 | `pattern, structure_note, sample_sentences[]` | content_pattern | structure_note 空→仅例句；sample 空→仅公式 |
| 练习题 | `quiz_question, quiz_options, quiz_answer` | content_word.quiz_* | 无 quiz→跳过练习标记完成 |
| 诊断题 | `difficulty_level` 标记池 | content_diagnostic | 不足则按相邻难度补 |
| 排序 | `difficulty_level, frequency_rank` | content_word | 空→原始顺序 |
