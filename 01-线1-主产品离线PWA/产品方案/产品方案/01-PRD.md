# 产品需求文档（PRD）v0.2 —「述树」零基础英语

> 状态：待确认｜版本：v0.2｜范围：MVP（Web App / 小程序，移动端优先）
> 说明：仅参考 Mobbin 的「交互模式」，不复制其品牌、截图、文案或受版权保护素材。

---

## 0. 一句话定位

**述树**是一款面向「中文母语、英语零基础成人」的移动端英语学习工具：用「中文辅助 + 点读慢速 + 即时反馈 + 每日小任务」，让用户在 **7 天敢开口、30 天能简单对话**。

---

## 1. 背景与核心问题

| 痛点 | 现状 | 述树的应对 |
|---|---|---|
| 怕难 | 传统成人英语一上来就是语法/长句，迅速劝退 | 从字母和发音起步，全程中文辅助 |
| 记不住 | 背了就忘，没有复习节奏 | 间隔重复 + 错题本 + 每日复习任务 |
| 坚持不下来 | 任务重、无正反馈、易中断 | 单任务 ≤ 5 分钟、连续天数、即时鼓励 |
| 没时间 | 只敢用碎片时间 | 通勤/午休/睡前即可完成「今日任务」 |

本质矛盾：**成人零基础用户不是学不会，而是被难度和中断劝退**。产品第一目标不是「教得多」，而是「让用户每天愿意回来」。

---

## 2. 目标用户画像

- **画像 A｜小琳，28 岁，职场新人**：上学时英语不及格，出国旅游全靠翻译软件；想学但不敢开口；每天通勤 40 分钟可学习。
- **画像 B｜老周，38 岁，个体经营者**：几乎零基础，需要接待外国客户；怕出错丢人；习惯睡前刷手机。
- **共性**：中文母语、18–40 岁、零基础/几乎零基础、怕难易弃、需要中文辅助、发音、即时反馈、每日小任务。

---

## 3. 核心目标与指标

### 学习成果目标
- **7 天**：掌握 26 个字母 + 基础发音（元音/辅音音标入门）。
- **30 天**：300 个基础词 + 20 个常用句型，能完成简单自我介绍与日常对话。

### 北极星指标
> **7 日留存率** —— 完成诊断后第 7 天仍打开并完成「今日任务」的用户占比。

### 关键指标（MVP 验证期目标）
| 指标 | 目标 |
|---|---|
| 次日留存 | ≥ 40% |
| 7 日留存 | ≥ 20% |
| 今日任务完成率 | ≥ 60% |
| 日均学习时长 | 5–10 分钟 |
| 跟读完成率 | ≥ 50% |
| 收藏率（人均收藏卡片数） | ≥ 5 |

---

## 4. 核心学习闭环

```
诊断测试 → 今日任务 → 知识卡（Linguabase 数据驱动）→ 单词/句型卡 → 听音跟读 → 练习 → 错题复习 → 奖励
```

每个环节都贯穿「中文辅助 + 即时反馈 + 鼓励」，形成「小输入 → 立刻练 → 马上被肯定 → 想再来一次」的正循环。

---

## 5. MVP 功能范围（映射需求）

1. **入门诊断（Linguabase 驱动）**：从 Linguabase 下载包中按 difficulty_level 字段分梯度抽取 5 道题，测试用户当前水平并定位学习起点。具体策略：
   - 第 1-2 题：从 difficulty_level=1（字母识别级）抽取，测试字母辨识能力；
   - 第 3-4 题：从 difficulty_level=2（基础词汇级）抽取，测试高频词认读能力；
   - 第 5 题：从 difficulty_level=3（简单句型级）抽取，测试句型理解能力。
   - 兜底规则：若前 2 题答错 ≥1 题，终止测试并推荐 difficulty_level=1 起始的学习计划；若全部答对，推荐 difficulty_level=3 起始的学习计划；中间结果对应 difficulty_level=2。
   - 测试过程无倒计时、无错误提示音，答错时仅显示鼓励文案（如「没关系，我们换个方式学」）并自动进入下一题。
   - 测试结果直接生成 Linguabase 中的起始 topic_id，写入用户学习计划。
2. **学习路径**：字母 → 音标/自然拼读 → 基础词汇 → 句型 → 简单对话。
3. **发现页**：卡片流，按主题 / 难度 / 场景 / 时长 / 技能筛选。
4. **学习卡片**：英文 + 中文 + 发音 + 图片 + 例句 + 点读 + 慢速 + 收藏。
   - 新增可选字段 `word_hint`（助记提示）：仅当该单词能通过简单拆分帮助记忆时才展示，且必须用大白话中文解释。示例：`inspect → "in(向内) + spect(看) = 向里面看 → 检查"`。
   - 该字段为后续「词素/词根」能力埋点：当前第一版不单独做词根模块，仅以极简提示提升现有 300 词记忆效率；未来可平滑扩展为系统化的构词解构，不影响现有卡片结构。
5. **知识卡（Linguabase 数据驱动）**：将 Linguabase 下载包中的结构化字段（word / ipa / definition_zh / example_en / example_zh / audio_path 等）自动映射为交互式学习卡片，前端按字段渲染，无人工内容编辑。字段缺失时静默降级（如 audio_path 为空则隐藏发音按钮，不显示报错）。
6. **练习**：选择 / 配对 / 填空 / 排序 / 听写 / 跟读。
7. **复习**：间隔重复、错题本、每日复习任务。
8. **收藏与集合**：收藏词/句/课，建集合（如「旅行英语」「餐厅点餐」）。
9. **AI 助手**：解释单词、纠错、生成例句、简单对话陪练（先轻量规则+小模型）。
10. **个人中心**：学习进度、连续天数、每日目标、提醒。
11. **设置**：中文辅助开关、语速、发音口音、深色模式。

---

## 6. 非目标（第一版明确不做）

社区、排行榜，直播，复杂语法树，付费系统。
> 理由：先保证零基础用户「学得会、愿意每天回来」，再谈增长与商业化。

---

## 7. 关键设计原则

- **零基础友好**：全中文辅助、点读、慢速、音标/拼音对照，绝不裸英文。
- **即时反馈**：每步对错即时反馈，以鼓励为主，错了给提示而非批评。
- **碎片化**：单任务 ≤ 5 分钟，支持断点续学。
- **渐进式**：诊断 → 路径 → 卡片 → 练习 → 复习，难度自动适配。
- **情感化**：鼓励文案、连续天数、轻量徽章（非公开排行榜）。

---

## 8. 关键交互模式（参考 Mobbin 模式，自有实现）

- **底部 Tab**：首页 / 发现 / 复习 / AI / 我的。
- **发现页**：顶部搜索 + 筛选 chips + 双列卡片网格。
- **卡片手势**：点击进详情；长按收藏；右滑 = 已掌握；左滑 = 加入错题。
- **学习流程**：顶部进度条 + 底部上一张/下一张 + 即时对错反馈。
- **状态覆盖**：空状态、加载骨架、错误重试均要设计。

### 视觉风格
干净、现代、留白充足、圆角卡片、柔和阴影、标签胶囊、大标题；支持深浅色模式。
**主色不超过 2 个 + 1 个强调色**，采用多巴胺风格绿色系：主色用鲜亮薄荷绿 / 草绿传递活力与生机，辅助色用沉稳深绿或暖白拉开层次，强调色用高饱和暖色（亮黄 / 珊瑚橙）承载「对 / 奖励 / CTA」。整体高饱和、愉悦、有记忆点，但控色克制不花哨。

---

## 9. 风险与假设

- **假设**：用户愿意每天投入 5–10 分钟；中文辅助显著提升完成率。
- **风险**：
  - 发音识别（ASR）准确率影响跟读反馈可信度；
  - TTS 自然度影响听感；
  - 内容质量（音标/中文释义/例句）一致性。
  - Linguabase 数据包字段完整性与零基础适配性风险（如部分单词可能缺中文释义或音频）。
- **缓解**：MVP 期用高质量录制音频 + 简单录音回放对比；AI 助手先用轻量规则 + 小模型，不强行上大模型；**内容完全依赖 Linguabase 下载包，无人工校验环节，通过字段映射规则和降级策略保障基础可用性**（字段映射与降级策略详见第 4 步「附录 A：Linguabase 字段映射与降级策略表」）。

---

## 10. 验收标准（概要，详见第 10 步）

- 完成诊断即生成可执行学习计划；
- 今日任务可在 5 分钟内完成；
- 卡片支持点读、慢速、中文解释、收藏；
- 练习提供即时对错反馈；
- 复习含间隔重复与错题本；
- 全部页面具备移动端 375px 适配、深色模式、空/加载/错误态。
