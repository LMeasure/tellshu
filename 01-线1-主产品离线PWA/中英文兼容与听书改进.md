# 粘贴文章中英文兼容 + 听书改进

按需求的四个部分实现并通过 112 项新单测 + 全套回归。下面逐条说明落在哪里。

## 一、新增模块

| 文件 | 职责 |
| --- | --- |
| `src/lib/textLang.ts` | 语言判断：字符占比 >80% 判纯中文 / 纯英文，其余为混合；`splitLangSpans` 按语言边界切片段 |
| `src/lib/speechText.ts` | 朗读文本清洗：去花括号、展开缩写、中文标点转英文标点、词根拆解符号处理 |
| `src/lib/voicePicker.ts` | 嗓音排序（纯函数，可单测）：中英分选 + localService 策略 |

## 二、需求对照

### 第一部分：语言判断
`detectLanguage(text)` —— `[\u4e00-\u9fa5]` 与 `[a-zA-Z]` 计数，占比 >0.8 才算纯某一种语言。
三者全覆盖，且无任何中英文字符时返回 `'en'`（与改造前行为一致，不回归）。

### 第二部分：英文路径
- 分词：原正则原样保留，一行未改。单测用 `tokenize(x,'auto') === tokenize(x,'en')` 把「零回归」钉成断言。
- 清洗四件事全部实现：**去 `{...}`**（含嵌套与未闭合）、**展开缩写**（e.g./i.e./etc./Mr./Mrs./Dr./vs.）、
  **中文标点转英文标点**（只在非中文句做，中文句保留原标点）、
  **词根记号** `un- + pre- + dict + -able` → `un, pre, dict, able`。
  词根规则只在检测到 `+` 时生效，所以 `well-known` 这类普通连字符单词不会被拆开。
- 分句朗读：原本已有按标点切句，这次补上 **句间 200ms 停顿**。
- 语速 `rate = 0.9`、音调 `pitch = 1.0`：在 `resolveRate` / `resolvePitch` 里定死为默认值。
- 中英嗓音分开选。

### 第三部分：中文路径
- 分词：`Intl.Segmenter('zh', {granularity:'word'})`，不可用时降级为逐字切分（`tokenizeChineseByChar`）。
  关键实现细节：**每个中文词必须各自成 token**，合并就整句变成一个空位、默写没法下手。
- 记忆模式：随机隐藏 / 完全隐藏 / 自主选择三种方式均支持中文。
- 核验：`inlineState` 本就是字符比对，中英文统一；MVP 不做拼音匹配。
- 标点切换：中文标点现在能独立成 token，「含标点」模式下会纳入默写。

### 第四部分：共用听书
- 按标点切句（英文 `.!?` / 中文 `。！？`），传 `{crossLanguage:true}` 时中英混排再按语言边界切一刀。
  默认关闭该开关，保证 `splitSentences` 老行为不变。
- **句子级高亮**：原来是整段一起亮，现在精确到句。
- **点击某句单独重读**：句子包一层可点容器，内部点词会 `stopPropagation`，不会误触发整句朗读。
- **嗓音选择**：中文优先 `zh-CN`/`zh-Hans`，英文优先 `en-US`→`en-GB`；
  联网时优先 `localService:false`（云端嗓音、音质好），断网时优先 `localService:true`（本地嗓音，否则一句也念不出来）。
  一个匹配嗓音都没有时才返回空，此时仍会显式设置 `utterance.lang`，不让引擎偷偷用系统默认嗓。

## 四、过程中发现并修掉的两个真缺陷

1. **中文词被合并成一个空位**——最初按「相邻同类片段合并」写 `tokenizeChinese`，结果整句变成一个 token。单测直接抓到了。
2. **停顿期间被抢占会无声死锁**——`suspend()` 会掐掉停顿定时器，如果不同时把 `await` 放行，loop 既不再往下读也收不到 `resume`。现在 `clearSleep()` 会一并兑现停顿 Promise。

## 六、怎么验证

```bash
npm run build
npm run preview -- --port 4174 --strictPort
```

打开 http://localhost:4174 —— **务必锁 4174**，你的生词数据在那个端口的 IndexedDB 里。

1. 进「我的 → 导入 → 文本」，粘贴一段中文，粘贴框下方会立刻显示「中文」标签
2. 保存后打开，阅读模式点词组可查词；**点任意一句会从该句开始朗读**，朗读到哪句哪句高亮
3. 切「记忆模式」，中文支持随机隐藏 / 完全隐藏（含标点会把 `。` 也纳入）/ 自主选择
4. 粘贴一段中英混排试试：会出现两种语言各自的分词与嗓音
