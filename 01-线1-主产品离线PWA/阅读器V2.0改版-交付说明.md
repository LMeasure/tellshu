## 一、改了什么

### 需求一 · 设置面板框架（阅读 / 记忆双 Tab）
- 顶部固定两个 Tab【阅读】【记忆】，**条件渲染**（切换即换内容，不做滑动隐藏）。
- 默认选中当前所在模式；**切换 Tab 同时切换阅读 ↔ 记忆模式**（原「模式」Segmented 并入 Tab）。
- 触发方式：① 单击正文呼出工具栏 → 点底栏最右「设置」图标开面板；② 面板内每个折叠项点右侧
  图标展开/收起（形如「黑体 ›」「覆盖翻页 ›」「语速 1.0x ›」）。

### 需求二 · 【阅读】Tab
- **排版**：字号（A− 滑杆 A+，带数值）/ 行距（紧—松）/ 边距（小—大）/ 首行缩进开关。
- **字体**（折叠）：楷体 / 黑体 / 宋体 —— `ReaderPrefs.fontFamily` 由 `sans|serif` 扩为 `kai|sans|serif`，
  三套系统真实字体栈（不引字体文件）。
- **翻页方式**（折叠）：平滑 / 覆盖 / 仿书本 / 上下滚动。
  - **平滑**：改为**三页连排**（上一页 / 当前页 / 下一页并排在一条 300% 宽的轨道里），
    手指横向拖动**跟手平移**、露出相邻页正文，松手按位移吸附 —— 连续「滚过去」而非一页换一页。
  - **覆盖**：去掉底页视差位移，新页**连同纸张整页盖到**上一面。
  - 除上下滚动外**不显示内置滚动条**；正文底部与底栏留常规间距（`pb-8`）。
- **听书**（折叠，见需求四）。
- **背景**（折叠，保留原能力）：亮度 + 纯白/羊皮/护眼/夜间 —— 白板图未画此项，但去掉会丢功能，
  故以折叠项保留（**假设项**）。

### 需求二之四 · 听书设置
- **定时关闭**：刻度滑杆，刻度 = 关 / 15 / 30 / 45 / 60 / 90（大字标注 关·30·60·90），
  选中有值后文案变「播放 mm:ss 后关闭」，倒计时到点**自动停止听书**；暂停时冻结、继续时续算。
- **本集结束后关闭**：开 = 读完本章（当前页）即停；关 = 读完**自动续读下一章**（默认关）。
- **语速**：0.5 / 0.75 / 1 / 1.25 / 1.5 / 2（沿用 `settings.speechRate`）。
- 听书时**单击正在朗读的句子 = 暂停，再点 = 继续**。

### 需求三 · 【记忆】Tab
- 「隐藏方式（随机/完全/自主）」「隐藏比例」「中英文目标」「含标点」四项设置移入此 Tab；
  正文里的**操作类**按钮（计时、清空本页、核验、录音）仍留在正文，避免设置与操作混在一起。

### 需求四 · 进度条

## 二、三个 Bug 的根因与修复

| # | 现象 | 根因（代码定位） | 修复 |
|---|---|---|---|
| 1 | 微信内听书无法播放 | 微信 WebView（X5/WKWebView）对 Web Speech 合成支持不可靠：`speechSynthesis` 存在但无声、且**拿不到任何错误回调**，属平台限制 | ① 新增 `isWeChatBrowser()` / `speechStatus()`，点播放时**明确提示**「请用浏览器打开」+ 设置面板内常驻说明；② `speak/speakAsync` 朗读前补 `speechSynthesis.resume()` 预热（对部分 paused 态内核有效）。**无法在纯前端彻底解决，需真机验证** |
| 2 | 做笔记无法保存 | `openThought`/`saveThought` 直接读 `popup`；想法框一开，系统收起选区触发 `selectionchange` → `setPopup(null)` → `saveThought` 里 `if (!popup) return` **静默不保存**（无接口/无登录态/无长度限制因素——本项目数据全在本地 IndexedDB，与账号同步无关） | 打开想法框即**快照选区**（`thoughtTargetRef`），保存以快照为准；弹窗交互期间冻结清空（`holdPopupRef`） |
| 3 | 两个弹窗重叠 / 划线弹窗出框 | 划词浮窗放在选区**正上方**，与系统原生选择菜单（复制/全选/搜一搜）位置冲突；展开划线样式行后高度增大，未重新测量 → 溢出视口 | 浮窗**默认放选区下方**（系统菜单在上方），放不下才翻到上方；展开后 `useLayoutEffect` **重新测量并横纵夹紧**；宽度上限 92vw |
