## 四、诚实边界（不编造）

- **OCR 依赖 PaddleOCR**：未配置时 `/convert/tasks/:id/ocr` 如实 503「OCR 服务未接入」，前端显错、绝不编造文本。
- **仅 PDF→PNG 支持 OCR 成文章**；其余五个方向仍 `ConverterNotImplemented`。
- **ZIP 为 store-only（不压缩）**，多页大体积 PDF 注意 80MB 上限（超出 413 提示分拆）。
- `tencent.ts` 仅改导入来源、调用点与行为完全不变（兼容此前所有调用），未删文件。

## 五、本地跑通

```bash
# 后端（开引擎 + OCR 需配 PaddleOCR 令牌）
cd server && CONVERT_ENGINE_ENABLED=true node dist/src/index.js
# Worker（装 PyMuPDF）
cd server && python -m venv .venv && pip install -r convert_worker/requirements.txt && python -m convert_worker.worker
# 前端
npm run preview -- --port 4174 --strictPort
# /import?tab=convert → 上传 PDF → 选 PNG → 完成 → 打包下载(ZIP) / OCR 成文章并保存
```
